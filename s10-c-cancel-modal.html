① 취소 처리 모달 주석

1
위약금 조회 (API 10)
모달 오픈 시점에 API 10 자동 호출.
DFLT_NM: 위약금 구간명 (PMS 설정값)
DLFT_APLY_AMT: PMS 납부 위약금 원금 (주의: API 10 실제 필드명 오타 — DLFT)
위약금율 = DLFT_APLY_AMT ÷ 입금가
고객 청구 위약금 = 위약금율 × 판매가 (소수점 첫째자리 반올림)
※ API 10 실패 시 모달 오류 표시 + 수동 입력 모드로 전환.
2
환불금액 자동 계산
환불금액 = 판매가 − 위약금 (자동 세팅).
부분취소(부분취소) 선행 이력이 있을 경우 계산 기준 정책 적용. (④ 뷰 참고 — A/B안 사업부 결정 후 반영)
※ 무료 취소(위약금 0): 환불금액 = 판매가 전액. 자동 진행.
3
환불금액 오버라이드
