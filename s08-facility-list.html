화면 주석

1 도메인 탭
PLACE 시설(숙소 시설 피커에서 사용) / ROOM 시설(객실 시설 피커에서 사용) 분리. 경로: #/facilities/place, #/facilities/room.
CM-FAC-01: 시설 도메인별 경로 분리.
2 시설 코드
영문 대문자. 등록 시 수동 입력. 수정 불가. 고유 식별자.
코드 중복 불가. 시설 코드는 내부 식별자로, 프런트에는 시설명만 표시됨.
3 시설명 (plain string)
한국어 단일 문자열. 다국어 { ko, en } 객체 아님. 실서비스에서 다국어 전환 예정.
→ 프런트: 숙소 레이어 시설 목록 항목명 / 상품 카드 시설 칩 텍스트 / Room Detail 시설 목록
4 카테고리 연결
시설이 속한 카테고리. 도메인 일치 카테고리만 선택 가능. 카테고리 헤더로 그룹핑하여 프런트에 표시됨.
→ 프런트: 시설 카테고리명이 그룹 헤더로 사용됨.
5 수정·삭제
수정: S08-B 시설 폼으로 이동. 삭제: 확인 다이얼로그 후 삭제.
숙소·객실의 facility_ids에 이미 포함된 시설을 삭제해도 참조 데이터는 즉시 정리되지 않음. 실서비스에서 참조 정합성 처리 필요.
