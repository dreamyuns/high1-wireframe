화면 주석

1
마진 목록 개요 — v0.2 객실 타입 단위
2단계 마진 계층의 1단계(객실 타입 마스터) 관리 화면. v0.2: 마진 단위가 시설(숙소) → 객실 타입(RM_TYP_CD)으로 세분화.
각 객실 타입에 기본 마진을 설정하면 해당 타입의 개별 마진 미설정 상품에 자동 적용된다.
마진 금액(정액) 입력 권장(소수점 없는 정확한 판매가). 상세 정책: s11-margin-policy.html 참조.
2
분류 탭 (숙소 / 티켓 / 투어)
숙소 탭: 시설(Place) 단위 마진 마스터. 티켓 탭: 카테고리(스키/워터파크 등 1뎁스) 단위 마진 마스터(하단 뷰 참고). 투어 탭은 추후 확장.
탭 전환 시 해당 분류의 마진 마스터 목록 로드. 숙소=시설별 / 티켓=카테고리별로 마스터 단위가 다름.
3
객실 타입 (RM_TYP_CD) — v0.2
마진 기본 단위가 객실 타입(RM_TYP_CD). RM_TYP_CD는 숙소별 독립 코드이므로 숙소명 병기(예: STD · 그랜드 메인타워). 코드는 객실관리(S04) PMS 동기화로 획득.
→ 프런트: 미노출 (운영 내부 기준 키)
4
마진 유형 — 마진금액 우선(★)
마진금액(원) — 보라 배지 ★ 권장 / 마진율(%) — 초록 배지(참고용) / 미설정 — 회색 배지.
v0.2: 마진 금액(정액) 방식을 우선·권장(판매가 정확 고정, 소수점 없음).
5
마진값
마진율: +N% / -N% 표기. 마진금액: +N,000원 / -N,000원 표기. 미설정: 대시(—).
6
판매가 예시
100,000원(마진율) 또는 해당 시설 최근 등록 상품 입금가(마진금액)에 마진을 적용한 예시 판매가. 참고용 표시이며 실제 상품 가격과 다를 수 있음.
7
적용 상품 수
해당 객실 타입(RM_TYP_CD) 상품 중 개별 마진 미설정(마스터 상속 중)인 상품 수. 마스터 마진 변경 시 이 수만큼의 상품 판매가가 즉시 변경된다.
마스터 변경 전 이 수치를 확인하여 영향 범위를 파악할 것.
