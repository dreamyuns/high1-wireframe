마진관리 — 숙소(객실 타입별) · 티켓(카테고리 마스터+쿠폰ID 오버라이드) 통합
숙소 7 티켓 8

여기서 설정한 마진이 상품 재고·요금(S06-B)의 일자별 마진 디폴트로 주입됩니다. 날짜별 개별 조정은 상품 재고·요금 탭에서 합니다. 전역 기본 디폴트: 마진금액 30,000원. 6

티켓 마진도 숙소와 동일한 목록 UI로 관리합니다. 상단 바에서 카테고리를 골라 마스터 마진을 정하면 그 카테고리의 쿠폰ID들이 값을 상속하고, 특정 쿠폰ID만 다르게 하려면 그 행에서 개별 설정으로 덮어씁니다(오버라이드). 한 쿠폰ID의 모든 레벨(대인·소인 등)에는 같은 마진이 적용됩니다. 9

S13 스펙 연동 15
이 목록의 쿠폰ID는 쿠폰 스펙(S13) CSV 업로드 시 자동 등록됩니다(신규=마진 미설정·상속 상태). 이 화면에서 쿠폰ID를 직접 추가하지 않습니다.
S13에서 기존 쿠폰ID의 카테고리가 변경되고 그 마진이 '상속'이면 새 카테고리 마스터로 재계산되며, S13 업로드 결과에 재계산 경고가 표시됩니다.

화면 주석 — S11 숙소·티켓 통합 마진관리

1
일괄 적용 바
숙소 필터(전체/특정 숙소)로 대상 행을 좁히고, 마진 유형·값을 지정한 뒤 [전체 적용] → 표시된 행에 일괄 반영. 화면 상단 고정.
'전체' = 모든 객실 타입. 특정 숙소 선택 시 해당 숙소 객실 타입만 대상.
2
행 단위 = 객실 타입(RM_TYP_CD)
등록된 객실의 RM_TYP_CD별로 1행 자동 생성(중복 타입은 1행). 숙소명·객실명은 참고 표시. 마진은 객실 타입 단위로 관리.
h1_margin_master_v1 = { [RM_TYP_CD]: { type, value } }
3
마진 유형 · 값 (인라인 편집)
전역 디폴트: 값 비활성, 전역 기본(마진금액 30,000원) 적용
마진금액: 정액(원). 판매가 = 입금가 + 금액 (권장)
마진율%: 정수 -49~+100. 판매가 = floor(입금가 × (1+율/100))
음수 = 할인 / 양수 = 마크업. 소수점 무조건 버림(floor).
4
판매가 예시 (실시간)
입금가 300,000원 기준 계산 결과를 행마다 실시간 미리보기. 유형·값 변경 시 즉시 갱신.
5
[마진 마스터 저장]
인라인/일괄 변경을 localStorage에 최종 반영. 저장 후 상품 재고·요금(S06-B)의 마진 미설정 일자에 디폴트로 주입된다.
6
마진 = 일자별 디폴트 주입 역할
S11 마스터는 객실 타입별 일자 마진의 초기 기본값. 실제 일자별 조정은 상품 재고·요금(S06-B) 구간 벌크에서 수행.
v0.6: 목록+상세폼 2화면 → 단일 인라인 편집 화면으로 통합(S11-B 폐기). "적용 상품 수·변경이력·마진 없음(0)" 제거, "마진 없음" 대신 "전역 디폴트(30,000원)". 티켓 탭은 재신설(아래 CN 7~14 참고).
7
[숙소] 탭
기존 숙소 마진 화면(객실 타입 RM_TYP_CD별 인라인 편집)입니다. 내용은 그대로 유지됩니다. 화면 진입 시 기본으로 열려 있는 탭입니다.
8
[티켓] 탭 (신설)
티켓 마진을 관리하는 신규 탭입니다. 숙소와 달리 쿠폰ID(coupon_id) 단위로 마진을 관리합니다. 탭을 누르면 티켓 화면으로 바뀝니다.
숙소=객실 타입 단위 / 티켓=쿠폰ID 단위. 저장 키가 서로 다릅니다.
9
티켓 마진 = 목록 UI (카테고리 마스터 + 쿠폰ID 오버라이드, v0.11 §11)
숙소 탭과 동일한 목록 UI입니다. 칩 드릴다운 없이, 상단 바에서 카테고리를 골라 마스터 마진을 정하고 아래 단일 목록에서 쿠폰ID별 상태를 봅니다.
① 카테고리 마스터: 카테고리(1뎁스)·상품유형(2뎁스)에 기본 마진을 정하면 그 아래 쿠폰ID가 상속합니다.
② 쿠폰ID 오버라이드: 특정 쿠폰ID만 개별 설정으로 덮어씁니다.
한 쿠폰ID의 모든 레벨(대인·소인 등)에 같은 마진 적용. 레벨은 마진 단위가 아닙니다. 미설정 시 전역 디폴트(마진금액 30,000원).
10
마진 적용 우선순위 (§11.3)
한 쿠폰ID에 여러 설정이 겹치면 번호가 작은 것이 우선합니다.
① 쿠폰ID 개별 → ② 2뎁스(상품유형) 마스터 → ③ 1뎁스(카테고리) 마스터 → ④ 전역 디폴트(마진금액 30,000원).
11
카테고리 마스터 마진 설정 바 (숙소 일괄적용 바와 동일 패턴)
카테고리 필터(전체/1뎁스/2뎁스)로 표시 범위를 좁히고, 마진 유형·값을 정한 뒤 [카테고리 마스터 적용]을 누르면 그 범위의 '상속' 행이 즉시 이 값으로 갱신됩니다.
'개별'로 설정된 쿠폰ID는 영향받지 않습니다. 숙소 탭의 [숙소 필터 + 전체 적용]과 같은 사상입니다.
12
[쿠폰ID 마진 저장]
인라인/일괄로 바꾼 마스터·오버라이드 마진을 localStorage에 최종 반영합니다. 변경일시·변경자·변경 전/후 값 이력 관리 필수.
h1_ticket_margin_master_v1 = { categories:{ "스키":{type,value}, "스키>리프트권":{type,value} }, overrides:{ "DBR":{type,value} } }  ※ 저장 키 확정은 미결(신규-4)
13
쿠폰ID 단일 목록 · 상속/개별 배지 · 개별 토글
선택 범위의 쿠폰ID 전체가 1개당 1행. 카테고리 컬럼으로 어느 카테고리 소속인지 표시(숙소의 숙소명·객실명 컬럼과 동일 역할).
상속(회색): 카테고리 마스터 값을 따름(읽기전용). 개별(초록): 오버라이드(편집 가능).
개별 토글 ON → 편집 활성 + '개별'. OFF → 마스터 복귀 + '상속'.
14
판매가 예시 (레벨별) · 마진 규칙
그 쿠폰ID의 레벨별 입금가에 같은 마진을 적용한 결과를 미리 보여줍니다. 예: 대인 40,000→44,000 / 소인 35,000→39,000. 유형·값 변경 시 즉시 갱신.
마진율 -49~+100 정수(소수점 입력 불가), 계산 결과 소수점은 무조건 버림(floor). 음수=할인 / 양수=마크업.
15
S13 스펙 연동 (§11.8)
티켓 마진 목록의 쿠폰ID는 S13 쿠폰 스펙 CSV 업로드 시 자동 등록된다(신규=상속 초기화). 이 화면에서 쿠폰ID를 직접 추가하지 않는다.
S13에서 카테고리·상품유형이 바뀐 쿠폰ID 중 '상속' 항목은 새 카테고리 마스터로 재계산되고, S13 업로드 결과에 재계산 경고가 표시된다. (정책 v0.11 11.8절)
