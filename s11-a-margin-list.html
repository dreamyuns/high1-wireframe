마진관리 — 숙소(객실 타입별) · 티켓(쿠폰ID 단위) 통합
숙소 7 티켓 8

여기서 설정한 마진이 상품 재고·요금(S06-B)의 일자별 마진 디폴트로 주입됩니다. 날짜별 개별 조정은 상품 재고·요금 탭에서 합니다. 전역 기본 디폴트: 마진금액 30,000원. 6

티켓 마진은 쿠폰ID(coupon_id) 단위로 관리합니다. 한 쿠폰ID의 모든 이용권 레벨(대인·소인 등)에 같은 마진이 적용됩니다. 카테고리는 쿠폰ID를 찾기 위한 필터·묶음 역할일 뿐, 마진은 카테고리가 아닌 쿠폰ID에 저장됩니다. 전역 기본 디폴트: 마진금액 30,000원. 9

화면 주석 — S11 숙소·티켓 통합 마진관리

1
일괄 적용 바
숙소 필터(전체/특정 숙소)로 대상 행을 좁히고, 마진 유형·값을 지정한 뒤 [전체 적용] → 표시된 행에 일괄 반영. 화면 상단 고정.
'전체' = 모든 객실 타입. 특정 숙소 선택 시 해당 숙소 객실 타입만 대상.
2
행 단위 = 객실 타입(RM_TYP_CD)
등록된 객실의 RM_TYP_CD별로 1행 자동 생성(중복 타입은 1행). 숙소명·객실명은 참고 표시. 마진은 객실 타입 단위로 관리.
h1_margin_master_v1 = { [RM_TYP_CD]: { type, value } }
3
마진 유형 · 값 (인라인 편집)
전역 디폴트: 값 비활성, 전역 기본(마진금액 30,000원) 적용
마진금액: 정액(원). 판매가 = 입금가 + 금액 (권장)
마진율%: 정수 -49~+100. 판매가 = floor(입금가 × (1+율/100))
음수 = 할인 / 양수 = 마크업. 소수점 무조건 버림(floor).
4
판매가 예시 (실시간)
입금가 300,000원 기준 계산 결과를 행마다 실시간 미리보기. 유형·값 변경 시 즉시 갱신.
5
[마진 마스터 저장]
인라인/일괄 변경을 localStorage에 최종 반영. 저장 후 상품 재고·요금(S06-B)의 마진 미설정 일자에 디폴트로 주입된다.
6
마진 = 일자별 디폴트 주입 역할
S11 마스터는 객실 타입별 일자 마진의 초기 기본값. 실제 일자별 조정은 상품 재고·요금(S06-B) 구간 벌크에서 수행.
v0.6: 목록+상세폼 2화면 → 단일 인라인 편집 화면으로 통합(S11-B 폐기). "적용 상품 수·변경이력·마진 없음(0)" 제거, "마진 없음" 대신 "전역 디폴트(30,000원)". 티켓 탭은 재신설(아래 CN 7~14 참고).
7
[숙소] 탭
기존 숙소 마진 화면(객실 타입 RM_TYP_CD별 인라인 편집)입니다. 내용은 그대로 유지됩니다. 화면 진입 시 기본으로 열려 있는 탭입니다.
8
[티켓] 탭 (신설)
티켓 마진을 관리하는 신규 탭입니다. 숙소와 달리 쿠폰ID(coupon_id) 단위로 마진을 관리합니다. 탭을 누르면 티켓 화면으로 바뀝니다.
숙소=객실 타입 단위 / 티켓=쿠폰ID 단위. 저장 키가 서로 다릅니다.
9
티켓 마진 = 쿠폰ID 단위
한 쿠폰ID의 모든 이용권 레벨(대인·소인 등)에 같은 마진이 적용됩니다. 레벨별로 따로 정하지 않습니다. 미설정 시 전역 디폴트(마진금액 30,000원) 적용.
h1_ticket_margin_master_v1 = { [coupon_id]: { type, value } }
10
카테고리 선택 (필터)
카테고리는 마진을 저장하는 단위가 아니라, 원하는 쿠폰ID를 빠르게 찾기 위한 필터·묶음입니다. 칩을 누르면 그 카테고리에 속한 쿠폰ID만 표에 표시됩니다.
'전체' 선택 시 모든 쿠폰ID 표시. 카테고리 자체에는 마진을 저장하지 않습니다.
11
일괄 적용 바 (티켓)
카테고리 필터로 대상 쿠폰ID를 좁히고, 마진 유형·값을 정한 뒤 [전체 적용] → 표시된 쿠폰ID 행에 한 번에 반영합니다. 저장은 [마진 마스터 저장]으로 확정.
12
행 단위 = 쿠폰ID(coupon_id)
쿠폰ID 1개당 1행입니다. 상품/이용권명·카테고리는 참고 표시입니다. 마진 유형·값은 CN 3(숙소와 동일 규칙)을 따릅니다.
13
판매가 예시 (레벨별)
그 쿠폰ID의 레벨별 입금가에 같은 마진을 적용한 결과를 미리 보여줍니다. 예: 대인 40,000→44,000 / 소인 35,000→39,000. 유형·값 변경 시 즉시 갱신.
14
[마진 마스터 저장] (티켓)
인라인/일괄 변경한 쿠폰ID별 마진을 localStorage에 최종 반영합니다. 변경일시·변경자·변경 전/후 값 이력 관리 필수.
