## v0.2.14 (2026-07-24) — 계층 뒤로가기(논리 네비 스택)
- 뒤로가기를 브라우저 history.back()에서 **자체 논리 스택 기반 계층 백**으로 변경. 탭 클릭 등 in-page 동작은 백 단계에 안 쌓임.
- 규칙: 새 페이지 진입=push(go) / 같은 숙소상세 형제 탭 전환=교체(goReplace) / 로고=스택 리셋 / 로그인 게이트=예약결제로 교체(백 시 로그인 화면 스킵).
- 뒤로가기=스택 pop → 직전 실제 페이지로 즉시 이동. 검증: 메인→호텔상세→탭×2→백=메인 / 메인→호텔상세→콘도상세→탭×2→백=호텔상세→백=메인.
- 적용: 검색결과·숙소상세·로그인·예약 백버튼, 드로어(전체메뉴) 링크, 홈 카드·view all, 검색 실행.

## v0.2 (2026-07-24) — 메인페이지 7개 수정 반영
- **1. GNB 재구성**: 헤더 = 로고 | 언어 셀렉트(🌐 EN/中文) | 로그인 | 전체메뉴(☰). 로그인 상태면 헤더 로그인 숨김(데모 토글). 전체메뉴 드로어를 `.device` 프레임 안에서 슬라이드(데스크톱에서도 폰 화면 내부에 표시) — drawer-scope 도입.
- **2. 히어로 ↔ 검색영역 분리**: 오버랩 제거, 검색영역 독립 블록. 히어로 슬라이드 1개에 CTA 버튼("View Packages", 라벨 임시) 추가.
- **3. 검색영역 픽토그램**: DATES/GUESTS/ROOMS 각 줄 좌측 아이콘(달력·사람·침대). 바텀시트도 동일 아이콘.
- **4. 아동 나이 + 객실 고정**: 아동 ≥1이면 아동 수만큼 나이 선택(만 0–12세). 객실 = 1 고정(스텝퍼 제거).
- **5. 추천영역 축소**: 카드 폭 84%→70%, 이미지 4:3→16:10, 폰트·여백·CTA 높이 축소.
- **6. 추천 탭 텍스트**: 15px→13px, padding·gap 축소.
- **7. 전체메뉴 아코디언**: 숙소/티켓 클릭 시 2뎁스 펼침/접힘. 로그인 버튼 최상단 1개만(로그인/가입 페이지 동일 → Sign up 제거). 드로어 언어 세그 제거(헤더로 이관).
- 검증: Edge 모바일(390) 홈·시트·아동나이·캘린더·드로어·아코디언·로그인토글·상세 + 데스크톱(900)에서 드로어 프레임 내부 표시 확인. 가로 오버플로 없음.
