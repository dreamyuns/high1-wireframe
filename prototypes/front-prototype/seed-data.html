High1 Seed Data v0.8 (티켓 데모주문 포함)

프로토타입 더미 데이터 주입 — 어드민·프런트 공용 localStorage

변경이력: v0.8 티켓 데모주문(사용완료 포함) 버튼 추가 · v0.7 티켓 도메인 더미 · v0.6 숙소 통합스펙 v1.0 기준

⚠️ 어드민(admin-prototype)과 프런트(front-prototype)는 같은 브라우저 저장소(localStorage)를 공유합니다. 이 페이지에서 한 번 주입하면 양쪽 모두 데이터가 채워집니다.
사용 방법 (개발사)
1) 아래 [전체 더미 주입] 클릭 — 재고·요금 날짜는 오늘 기준 +120일로 자동 생성됩니다(언제 열어도 검색결과가 보임).
2) 어드민 / 프런트 페이지를 새로고침 → 숙소·객실·상품·이미지·요금 노출 확인.
3) 데이터를 지우려면 [전체 초기화].
더미 데이터
티켓 데모 주문 (마이페이지·어드민 S15 테스트용)
전부미사용 · 일부사용 · 전부사용완료 · 부분취소 · 3상태혼합 · 취소완료 · 사용기간만료 · 단일대량 (국가 KR/CN/JP/US/TW/HK/TH/SG)

프런트에서 먼저 로그인한 뒤 이 버튼을 누르면 로그인 계정으로 데모 주문 1건이 생성됩니다.
구성: 스키 리프트 종일권(대인 2·소인 1) + 장비렌탈(대인 1) — 이 중 대인 1장 = 사용완료(USED).
→ 마이페이지 주문 상세에서 사용완료 쿠폰은 취소 대상에서 제외(취소·환불 불가), 미사용만 부분취소되는 걸 확인.
