# High1 프런트 디자인 가이드

> 기준: 프런트 프로토타입 `front-prototype` **v0.8.18** (2026-07-14)
> 원본: `styles.css` / `app.js` / `index.html`
> 목적: 프런트(고객) 화면의 색상·타이포·간격·컴포넌트 규칙을 정리한 참조 문서. 개발사·디자이너가 실제 UI 구현/확장 시 기준으로 사용.

---

## 1. 개요

- **대상 사용자**: 외국인 고객 (영어 기본, 다국어 확장 대비)
- **구성**: 정적 SPA (HTML + Vanilla JS + localStorage, 해시 라우팅). 빌드 도구 없음.
- **디자인 톤**: 다크 네이비 헤더 + 밝은 베이지 배경 + 브라운 CTA. 리조트/호텔 예약 톤앤매너.
- **적용 화면**: 메인 · 숙소 검색결과/브릿지 · 상품(객실) 카드 · 예약(투숙자)·결제·완료 · 로그인 · 마이페이지(목록·상세) · 티켓 검색/브릿지/상세.

## 5. 컴포넌트

### 5.1 GNB (상단 헤더)

- 배경 `--navy`, 높이 `64px`, `position: sticky` (스크롤 고정)
- 구성(좌→우): **로고 이미지**(`logo.png`, 높이 28px) │ 언어 셀렉트 │ Accommodation▾ │ Ticket▾ │ Mypage▾ │ Sign in/up
- 드롭다운(`.gnb-acc-menu`): 흰 배경, `--r-md` 근사(8px), `--shadow-md`, hover 시 노출
- **로그인 상태**: `Sign in/up` 버튼 숨김, Mypage ▸ Log out 노출

### 5.2 언어 셀렉트 (`.lang-select`)

- 다크 GNB용: 반투명 흰 배경 `rgba(255,255,255,.08)`, 흰 글자, 커스텀 화살표
- 옵션: **English / 中文 / 한국어** (다국어 3개+ 확장 대비). 선택값 `localStorage` 유지.

### 5.3 버튼

| 종류 | 스타일 | 용도 |
|---|---|---|
| 주요 CTA `.btn-cta` | 배경 `--cta`(브라운), 흰 글자, 700, `--r-sm`, 폭 100% | 결제·계속·홈 등 확정 액션 |
| 아웃라인 `.btn-outline` | 흰 배경, `#d8dee8` 테두리, 호버 시 퍼플 | 취소·보조 액션 |
| 다크 `.login-btn` | 배경 `--navy` | 로그인 제출 |
| 검색 | 퍼플 `#7c3aed` | 검색 실행 |
| 비활성 | 배경 `#c8c8c0`, `not-allowed` | disabled |

### 5.4 카드

- **상품(객실) 카드 `.product-card`**: 3열 그리드(썸네일 220px / 본문 / 가격패널 172px), `--r-lg`, `--shadow-sm`, 호버 시 `translateY(-2px)` + `--shadow-md`. **카드 전체 클릭 → 예약(로딩 1초)**, 썸네일 화살표·[Room Detail] 버튼은 `stopPropagation`.
- **예약 카드 `.my-card`**: 상단(유형·상태 배지·번호) + 본문(좌 이미지 150×110 / 우 정보). 인원·일정·예약일·금액. 예정 숙소 카드에 **체크인 D-day 뱃지**(퍼플).
- 공통: 흰 배경, `--r-md`, 호버 부양 효과.

### 5.5 폼 (input / label / select)

- 입력 `.bk-input`/`.login-input`: 폭 100%, 패딩 `12px 14px`, 테두리 `#d8dee8`, `--r-sm`(8px), 포커스 시 테두리 `#7c3aed`
- 라벨: 12px, 600, `#555`, 하단 여백 5px. 선택 항목은 "(선택)" 명시
- 오류 문구: `#c0392b`, 12.5px
- 2열 입력: `.bk-row2` (First/Last name, 유효기간/CVC 등)

### 5.6 테이블 (요약·상세)

- `.bk-sum-tbl`: 라벨(th, 좌측·회색) + 값(td, 우측). border-collapse.
- 카드형 테이블 `.bk-done-tbl`: 흰 배경 + `--r-md` 테두리. **주의**: 둥근 테두리 안에서 좌우 여백이 필요하면 `border-collapse: separate; border-spacing:0`로 지정(collapse 모델은 table padding 무시).

### 5.7 스텝 인디케이터 (`.bk-steps`)

- 예약 흐름 3단계: `1 투숙자 → 2 결제 → 3 완료`
- 현재 단계 `.on`(네이비 채움) / 완료 `.done`(연녹색) / 대기(회색 pill)

### 5.8 홀딩 타이머 (`.bk-hold`)

- 경고 톤(오렌지 계열) 바, `mm:ss` monospace 카운트다운. 만료 시 예약 해제.

### 5.9 모달

- 취소 확인 `.my-modal-back`(반투명 오버레이 `rgba(0,0,0,.45)`) + `.my-modal`(흰 카드, `--r-lg` 근사 14px, `--shadow-lg`)
- 예상 환불액 강조 표시 + [닫기]/[취소하기] 2버튼
- 객실 상세 모달 `.rd-modal`, 숙소 정보 레이어 `.layer` 동일 패턴(배경 backdrop + 흰 패널)

### 5.10 로딩 오버레이

- `showLoadingOverlay(text)` / `hideLoadingOverlay()` — 전체 화면 반투명 + 안내 문구. 검색·예약 진입(1초) 등 전환 시.

### 5.11 고객센터 블록 (`.my-support`)

- 연회색 박스, 전화·이메일·운영시간 3항목 가로 배치. 상세 화면 공용.

## 6. 다국어(언어) 규칙

- **구조적 UI**(GNB·섹션 제목·카드 뱃지·버튼)는 **영어 고정**. 코드 내 헬퍼 `t()` / `L(ko,en)` 사용.
- **콘텐츠명**(숙소·객실·상품명 등)은 언어별 값 사용: `name_en`(필수) / `name_zh`(선택, 미입력 시 EN 대체) / 개발단계 KO 병행.
- 현재 `L(ko,en)` 헬퍼는 KO/EN 2언어 기준. **中文(zh) 선택 시** 콘텐츠명은 `name_zh`가 있으면 표시되나, 일부 구조 라벨은 KO로 폴백됨 → 中文 구조 라벨 완성 시 사전 확장 필요.

## 8. 반응형

| 브레이크포인트 | 변화 |
|---|---|
| `≤ 820px` | 예약/결제 2단(폼+요약) → 1단, 요약 카드 `position: static` |
| `≤ 640px` | 마이페이지 카드 본문 세로 적층(이미지 상단 풀폭), 상세 이미지 풀폭 |

- 이미지 `object-fit: cover`, 넓은 표는 `overflow-x: auto` 컨테이너로 감쌈.

### 8.1 리치 콘텐츠 삽입 이미지 (중요)

- 관리자가 리치 에디터로 넣은 콘텐츠(객실 정책·안내, 숙소 정보 레이어 등)의 `<img>`는 **반드시 컨테이너 폭에 맞춰 자동 축소**해야 한다. 규칙: `max-width: 100%; height: auto; display: block`.
- 적용 대상 컨테이너: `.rd-sec`(객실 상세 모달 섹션) · `.layer-body`(숙소 정보 레이어) · `.tkf-detail-html`(티켓 상세). **새 리치 콘텐츠 렌더 지점 추가 시 동일 규칙 필수** (누락 시 가로 스크롤·잘림 발생).
- 세로로 긴 이미지는 세로 스크롤 허용(가로 폭만 맞춤). 실전송 용량 최적화는 업로드 축소 + (실서비스) CDN URL 변환으로 처리.
- **어드민 가이드**: 리치 에디터 입력부에 표준 안내 문구 노출 — "화면 폭에 맞춰 자동 축소 표시 · 가로가 긴 이미지 권장(≥800px) · 세로로 긴 캡처 지양".

## 10. 유지보수 메모

- 색상/간격은 **CSS 변수 우선** 사용, 리터럴 최소화. 특히 액센트 퍼플 `#7c3aed`는 `--accent` 토큰화 후보.
- 새 화면 추가 시: 배경 `--bg`, 카드 `--surface`+`--r-md`+`--shadow-sm`, 제목 `--navy`, 주요 액션 `.btn-cta`, 보조 `.btn-outline` 재사용.
- 상태 색상(성공/대기/취소, 무료취소/환불불가)은 4장 규칙을 그대로 따른다.
- 고객센터 값(이메일·운영시간)은 현재 프로토타입 임시값 — 실제 값 확정 필요.
