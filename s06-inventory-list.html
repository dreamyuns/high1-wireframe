화면 주석

1
편집 중인 상품 컨텍스트
탭1(S06-A)에서 선택된 숙소·객실·상품명을 상단에 표시. S06-A ↔ S06-B 간 이동 시 상품 정보 유지.
2
탭2 — 재고·요금 (인벤토리)
탭2는 목록형(S06-B)과 달력형(S06-C)으로 분리. 탭1(S06-A) 상품 마스터 저장 완료 후 탭2에서 인벤토리 입력.
3
목록형 뷰 (읽기전용 조회 + 마진·예약조건 행별 편집)
날짜 행별로 입금가·마진·판매가·재고·예약조건·상태를 테이블로 표시. 날짜·입금가·재고·판매상태는 읽기전용(PMS/S04-INV 연동). 마진(유형·값)과 예약조건(최소/최대박·컷오프)은 각 행에서 직접 편집할 수 있고, 상단 구간 일괄(벌크)로도 덮어쓸 수 있다. 날짜(행) 추가·삭제는 없음.
달력형(S06-C)과 동일한 inventory[] 데이터. 재고·요금은 두 뷰 모두 조회만, 마진·예약조건은 편집 가능.
4
예약조건·마진 구간 일괄(벌크) 적용
시작일~종료일 + 최소박·최대박·컷오프(예약조건) + 마진 유형·마진 값(마진)을 한 번에 입력 후 '일괄 적용' 클릭. 해당 범위 날짜의 예약조건과 마진을 함께 덮어씀.
입금가·재고는 이 패널에 없음 — 읽기전용(PMS/S04-INV)이므로 벌크 대상에서 제외. 날짜 신규 생성도 없음(PMS 연동 날짜만 존재).
벌크는 행별 편집을 대체하지 않는 보조 수단 — 넓은 구간을 한 번에 맞출 때 사용하고, 특정 날짜만 다르게 하려면 아래 테이블에서 행별로 직접 수정한다. 마진 미설정('없음') 시 마진 마스터(S11) 전역 디폴트 30,000원 적용.
5
기간 필터
인벤토리 행이 많을 때 특정 기간만 조회. 필터 적용 시 해당 범위 행만 표시됨.
6
입금가 (price) — 읽기전용
해당 날짜의 1박 원가 (KRW). 이 화면에서 수정 불가(읽기전용). PMS(API 3, SELL_ITM_AMT) 연동으로 수신하며, 요금 갱신은 S04-INV(객실 타입) 요금 동기화에서 수행한다. 마진 미적용 금액. (API 4 SELL_ITM_AMT 무시 확정)
→ 프런트: 미노출 (고객에게는 판매가만 표시)
20
판매가 (sell price) — 읽기 전용
입금가에 마진(S11 시설 마스터 또는 S06-A 상품 개별)을 적용한 고객 청구 금액. 자동 계산, 직접 수정 불가. 마진 변경 시 실시간 반영.
계산식: 입금가 × (1 + 마진율) 또는 입금가 + 마진금액. 소수점 버림(floor). 다박 예약 시 숙박 일수만큼 각 날짜 판매가 합산.
→ 프런트: 상품 카드 총 금액 (multi-night sum, 판매가 기준). API 6 SELL_AMT는 입금가로 전송 (판매가 아님).
7
사용가능 객실수 (읽기전용)
해당 날짜 남은 판매 가능 수량. 이 화면에서 수정 불가.
PMS연동 상품: API 4 RSV_CNT 값. 수기 상품: 총 재고 − 예약 수.
재고 변경은 객실 상세 > 재고관리 탭에서 수행. 0이면 SOLD OUT 표시.
→ 프런트: stock ≤ 0 → 상품 카드 'SOLD OUT' 상태
8
최소박 / 최대박 (min_stay_nights / max_stay_nights)
체크인일 기준 적용. 선택한 박수가 [min, max] 범위 밖이면 예약 불가.
→ 프런트: 박수 범위 벗어나면 상품 카드 '최소/최대 박수 제한' 상태
9
컷오프 (cutoff_days_before_checkin)
체크인 N일 전 자정부터 예약 차단. N=0이면 컷오프 없음 (당일 예약 가능).
→ 프런트: today ≥ (체크인 − N일) 이면 '예약 마감' 상태
10
상태 배지
각 날짜 행의 현재 상태를 시각화. 정상(초록) / SOLD OUT(빨강, stock=0) / 체크인불가(회색, check_in_allowed=N).
11
편집 범위 — 예약조건·마진
이 화면은 날짜·입금가·판매가·재고를 조회(읽기전용)만 하고, 예약조건(최소/최대박·컷오프)과 마진(유형·값)만 구간 일괄(벌크)로 변경한다.
날짜는 PMS 연동으로만 생성되므로 관리자 날짜 추가·삭제·중복 검증이 필요 없다.
12
판매 ON/OFF (읽기전용 · S04-INV 관리)
해당 일자의 판매 가능 여부. 이 화면에서는 읽기전용 조회만 하며, 편집은 S04-INV(객실 타입 인벤토리)에서 일자별 판매 ON/OFF로 수행한다(정책서 5절). 기존 '체크인허용' 개념을 대체.
→ 프런트: OFF(마감) 일자를 체크인일로 선택하면 "예약 불가(마감)" 표시. 재고 0 → 자동 SOLD OUT.
객실 타입 단위로 S04-INV에서 OFF 시, 연결된 모든 상품(S06)에 즉시 반영. S06에서는 조회만.
17
하단 [저장] 버튼 — 예약조건·마진
구간 일괄(벌크)로 적용한 예약조건(최소/최대박·컷오프)과 마진(유형·값)을 localStorage에 최종 기록. 입금가·판매가·재고는 읽기전용이라 저장 대상이 아니다(PMS/S04-INV 원본 유지).
탭1(S06-A) 마스터 저장과 독립적으로 동작.
18
하단 [취소] 버튼
벌크로 적용한 예약조건·마진 변경을 파기하고 상품 목록(S05)으로 이동.
localStorage에 저장되지 않은 변경만 파기됨. 이미 저장된 데이터는 유지.
19
재고·요금·날짜 읽기전용 안내
날짜·입금가·판매가·재고는 이 화면에서 수정·추가·삭제 불가(읽기전용).
요금(입금가)은 S04-INV(객실 타입)에서 PMS(API 3, SELL_ITM_AMT) 동기화로 갱신 → 상품은 그 값을 참조해 표시만. 재고(API 4 AVLB_RM_CNT)도 S04-INV/PMS 연동. 날짜(인벤토리 행)는 PMS 연동으로만 생성됨.
[요금 동기화] 버튼은 S06에서 제거됨 — 요금 갱신 창구는 S04-INV로 일원화. API 4 SELL_ITM_AMT 무시 확정 (하이원 2026-05-27).
전 상품 PMS 연동 운영 전제. 이 화면의 편집 대상은 예약조건(최소/최대박·컷오프)과 마진(유형·값)이며, 구간 일괄(벌크)로만 설정한다.
21
이력 보기 (B안 — 날짜 필터 모달)
필터 바 오른쪽 [이력 보기] 버튼 클릭 시 변경이력 조회 모달 표시.
조회기간(시작일~종료일) 설정 후 [조회] 클릭 → 해당 기간 내 날짜별 인벤토리 변경 이력만 필터링 표시.
이력 기록 조건: 날짜별 입금가·재고 변경 시 자동 기록 (수동 저장 시점 기준).
이력 컬럼: 변경일시 / 변경자 / 적용날짜 / 변경구분(수동·PMS동기화) / 항목 / 변경 전 / 변경 후.
수동 변경과 PMS동기화는 배지로 구분. PMS동기화 이력은 별도 동기화 로그 테이블에서 조회.
22
마진 컬럼 — 날짜(행)별 편집
테이블의 마진 컬럼은 각 행(날짜)에서 직접 편집한다. 유형 select(없음 / 마진금액 / 마진율%) + 값 input으로 입력하며, 유형이 '없음'이면 값 입력이 비활성된다.
개별 배지 = 관리자가 그 날짜에 직접 지정(manual), 상속 배지 = 마진 마스터(S11) 값을 상속(master). 판매가 = 입금가 + 마진(유형·값 기준)으로 자동 계산되어 옆 칸에 표시.
여러 날짜를 한 번에 맞추려면 상단 구간 벌크를 쓰고, 특정 날짜만 다르게 하려면 이 컬럼에서 행별로 수정한다.
유형 '없음'(상속) 시 마진 마스터(S11) 전역 디폴트 30,000원이 적용된다. 마진율(%) 범위(-49~+100)·소수점 버림 등 세부 규칙은 S11 마진관리 정책을 따른다.
