S15-B 티켓 주문 상세 — 예약관리 GNB / 티켓 예약·주문 / #/ticket-orders/:id
티켓 주문 1건의 전체 정보 화면. 주문·고객·발급 쿠폰 확인 + 취소/환불 처리. 1주문 = N장 쿠폰(쿠폰 단위 현황은 S16).
취소는 전체취소만 — 부분취소·부분환불 없음. 취소 시 연결 쿠폰 전부 SOLD → CANCELED.

화면 주석

1
헤더 — 주문번호 · 상태 · 취소하기
주문번호(ORD-YYYYMMDD-NNNNN)와 주문상태 배지(결제완료 / 취소완료 2종 — 대기·취소요청 없음, 5.3절)·사용상태 배지(미사용 / 일부사용 / 사용완료)를 함께 보여준다.
우측 [취소하기]는 전체취소만 실행한다. 부분취소 버튼은 없다. 이미 취소완료된 주문은 읽기 전용(버튼 숨김).
2
주문 기본정보
상품명·수량(레벨별)·결제금액(판매가)·결제수단·결제일시·사용상태를 표시한다. 결제금액은 판매가(입금가+마진, 고객 청구 금액)다.
사용상태는 연결 쿠폰의 사용 여부를 집계한 값이다(미사용 / 일부사용 / 사용완료). 집계 규칙은 S15 목록 CN8과 동일하다.
3
구매자 · 투숙자 정보
성(Last)·이름(First)·이메일·전화·국적을 표시한다. 티켓은 국적만 수집하고 여권번호는 받지 않는다(항상 "미수집").
→ 프런트: 이메일로 주문 확인·쿠폰 발급 안내 발송
4
발급 쿠폰 목록 (7컬럼)
이 주문으로 발급된 12자리 바코드 쿠폰을 장수(N장)만큼 나열한다. 컬럼: 쿠폰번호 · 쿠폰명/레벨 · 쿠폰 상태(SOLD/USED/CANCELED) · 입금가 · 판매가 · 사용기간 · 사용일시.
입금가는 High1 납부 원가로 정산용·고객 미노출. 판매가=입금가+마진(고객 청구). 사용일시는 High1 /use 호출 시각으로 USED 쿠폰만 표시(SOLD/CANCELED는 공란). → 정산 시 어느 쿠폰이 얼마에 납부·언제 사용됐는지 한 화면에서 확인(v0.8).
쿠폰번호 = 쿠폰ID 3 + 레벨 1 + 일련번호 6 + 유효번호 2 = 총 12자리. [S16 발급현황]으로 쿠폰 단위 발급현황(S16)과 연결된다.
취소·환불 처리 시 이 주문의 쿠폰 전부가 SOLD → CANCELED로 바뀐다.
5
취소 / 환불 — 전체취소만
자동: S14-B 취소정책으로 취소 시점의 위약금율을 적용해 환불 예정액을 자동 계산한다. 위약금 = 판매가 × 위약금율.
수동: 자동 계산을 쓰지 않고 관리자가 환불금액·위약금을 직접 입력한다(예외·민원 대응).
부분취소·부분환불은 없다. 항상 주문 전체를 취소한다. 이 점이 이전 버전(부분환불 지원)과 달라진 부분이다.
환불 실행 주체(PG 연동)는 결제 시스템 담당. 본 화면은 상태·금액 확정까지만 처리한다.
6
취소 사유
취소·환불 처리 시 사유를 입력한다. 처리하면 변경 이력에 함께 기록된다.
7
변경 이력 (접이식)
제목을 누르면 펼쳐지는 접이식 영역이다. 주문 생성·쿠폰 발급·취소요청·취소/환불 처리 등 주요 이벤트를 시간순으로 기록한다.
처리자: SYSTEM(자동) 또는 관리자 ID(수동).
