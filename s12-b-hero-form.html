취소 저장

화면 주석

1
미디어 유형 선택
이미지: PC 이미지 + 모바일 이미지 두 파일 등록.
동영상: 동영상 파일 + PC·모바일 썸네일 이미지(동영상 시작 전 표시) 등록.
유형 변경 시 이미 업로드된 파일은 초기화.
2
PC 이미지 규격
권장: 1920 × 600 px · 최대 5 MB · JPG/PNG/WebP.
가로로 긴 비율(와이드)로 등록해야 PC 화면에서 여백 없이 표시됩니다.
규격 외 이미지도 업로드 허용하되, 미리보기로 노출 결과를 확인할 것.
3
모바일 이미지 규격
권장: 768 × 450 px · 최대 3 MB · JPG/PNG/WebP.
PC 이미지를 모바일에도 사용하면 중앙 크롭으로 처리되어 이미지 상하단이 잘릴 수 있습니다.
모바일 최적화 이미지를 별도 등록하는 것을 권장합니다.
→ 프런트: 모바일(~768px) 화면에서 모바일 이미지 우선 표시
4
동영상 파일 규격
허용 형식: mp4, webm · 최대 100 MB.
모바일 브라우저(Chrome/Safari) 정책상 사운드 있는 동영상 자동재생 불가 → 음소거(muted) 강제 적용.
배경용 영상은 음소거로 제작하거나 사운드 없는 영상을 사용하는 것을 권장합니다.
개발사 확인: 동영상 로딩 전 썸네일 이미지 표시 구현 필요.
5
동영상 자동 재생
ON: 슬라이드가 화면에 나타날 때 자동 재생 시작 (muted 강제).
OFF: 고객이 재생 버튼을 눌러야 동영상 시작.
6
텍스트 — 다국어 (KO/EN)
타이틀·서브타이틀을 KO/EN 각각 입력. 프런트 언어 설정에 따라 해당 언어 텍스트 노출.
EN 미입력 시 KO 텍스트로 대체.
→ 프런트: 슬라이드 이미지 위 오버레이 텍스트로 표시
7
노출 기간
시작일·종료일 모두 비워두면 상시 노출.
종료일 자정 경과 시 상태 자동 OFF (목록에서 슬라이드는 유지, 프런트 미노출).
8
강제 종료
ON 설정 시 노출 기간·자동 슬라이드 설정과 무관하게 이 슬라이드를 즉시 비활성화.
긴급 수정이 필요한 경우 슬라이드를 삭제하지 않고 임시 OFF 처리할 때 사용.
강제 종료 ON 상태에서는 S12-A 목록에 주황색 "강제종료" 배지 표시.
9
CTA 버튼 — 개요
사용 toggle OFF 시 CTA 버튼 미노출 (텍스트 입력란 숨김 처리).
사용 toggle ON 시 버튼명(KO/EN)·URL 입력 필수.
→ 프런트: 슬라이드 하단 중앙 고정 위치에 CTA 버튼 표시
10
CTA 버튼명 (KO/EN)
KO/EN 각각 입력. EN 미입력 시 KO 버튼명으로 대체.
11
링크 URL
내부 링크: /hotel, /condo, /hotel?tab=palace 등 경로 직접 입력.
외부 링크: https://… 로 시작하는 URL — 새 탭으로 자동 오픈.
내부 링크는 현재 탭에서 이동.
