· 스펙 선행: 연결할 S13 스펙이 있어야 등록 가능. 카테고리를 고르면 그 카테고리 스펙만 자동 필터되고, 1개면 자동 선택. 스펙의 레벨·입금가·사용기간이 자동 로드된다.
· 콘텐츠 소유(A안): 상품은 썸네일만 등록. 상세설명·이용안내·정책·위치·히어로 이미지는 카테고리/컨텐츠 관리(S17)에서 뎁스 단위로 관리(상품별 히어로·상세정보 탭 폐지).
· 마진은 이 화면에서 편집하지 않는다. S11 마진관리(티켓 탭)에서 쿠폰ID 단위로 설정한 값을 읽기전용으로 표시(판매가 = 입금가 + 마진, 소수점 버림).
· 취소정책은 오픈형 고정 — 오픈형은 이용일이 없어 이용일 기준 구간을 설정하지 않고, 사용기간 종료일 기준 규칙이 자동 적용(읽기전용 표시). 편집 UI 없음.
· 판매기간: 판매시작일 미설정=즉시 판매 / 판매종료일 미설정=노출 토글로만 제어. 종료일 자정 경과 시 자동 미노출. High1 사용기간과 별개.
· 입금가(원가) 고객 미노출. 상품명 등 텍스트는 EN(필수) / ZH(선택), 국문(KO) 미사용.

① 기본정보

판매기간(우리 홈페이지 판매 가능 기간)은 High1 사용기간(현장 입장 가능 기간)과 별개입니다. 판매종료일 자정 경과 시 프런트 자동 미노출.

화면 주석

1
2탭 구조 (탭1 마스터 / 탭2 날짜)
탭1 상품 마스터(기본정보·레벨/판매가·취소정책·썸네일)와 탭2 날짜 설정(S14-C)으로 분리. 날짜 방식·커트오프는 전부 탭2.
두 탭은 같은 상품의 서로 다른 영역을 편집. 저장 버튼은 공통.
2
상품명 (EN 필수 / ZH 선택)
고객에게 보이는 상품 이름. 데이터 성격: 어드민 직접입력. 값 형식: 자유 텍스트. 영어(EN)는 필수(비우면 저장 불가), 중국어(ZH)는 선택(비우면 EN 대체 노출). 국문(KO) 미입력.
→ 프런트: 티켓 상품 카드·상세 타이틀
3
카테고리 1뎁스 / 2뎁스
데이터 성격: 어드민 선택(S17 티켓 카테고리 트리 기준). 최대 2뎁스. 1뎁스 필수(예: 스키·워터파크). 2뎁스(상품유형, 예: 리프트권)는 하위가 있는 카테고리만 선택 가능, 없으면 "— 없음"으로 비활성.
카테고리를 바꾸면 아래 연결 스펙 후보가 다시 필터되고 선택이 초기화됨.
4
연결 스펙 (쿠폰ID · 카테고리 자동 필터)
데이터 성격: 어드민 선택(S13 스펙 중). 값 형식: 쿠폰ID — 이용권명. 선택한 카테고리(+상품유형)에 해당하는 스펙만 드롭다운에 표시되고, 후보가 1개면 자동 선택. 선택 즉시 ② 레벨·입금가·사용기간이 자동 로드.
카테고리 미선택 시 "먼저 카테고리를 선택하세요", 후보 없으면 "연결 가능한 스펙 없음". 스펙 없이는 저장 불가(스펙 선행 원칙).
5
노출 여부
데이터 성격: 어드민 선택(노출/미노출). 상품 단위 노출 스위치. 프런트 노출 = 연결 스펙 ON AND 상품 노출 ON AND 판매중(3개 모두 충족).
미노출 조건(OR): ① 상품 노출 OFF ② 판매종료 초과 ③ 연결 스펙 OFF(🔒 Cascade). 목록(S14-A)에서 상태 배지로 확인.
6
판매 시작일 / 판매 종료일 (선택 입력)
데이터 성격: 어드민 입력(date, 선택). 값 형식: YYYY-MM-DD. 시작일 미설정 = 즉시 판매, 종료일 미설정 = 노출 토글로만 제어. 종료일 설정 시 자정(00:00) 경과하면 자동 미노출.
종료일은 시작일 이후여야 함(설정 시). High1 사용기간(현장 입장)과 별개 개념.
7
[표] 레벨
연결 스펙의 판매 옵션. 값 형식: LV.N + 레벨명(예: LV.1 대인 / LV.2 소인). 데이터 성격: 스펙에서 자동 로드(읽기전용). 레벨 구성은 스펙에 따라 다름(2레벨 또는 1레벨).
8
[표] 입금가
High1 납부 원가. 값 형식: NN,NNN원. 데이터 성격: 스펙에서 자동 로드(읽기전용). 고객 미노출. 판매가 계산의 출발점.
→ 프런트: 미노출
9
[표] 적용 마진 (S11 · 읽기전용)
입금가에 얹는 이익. 값 형식: 율 10% 또는 정액 +4,000원. 데이터 성격: S11 마진관리(쿠폰ID 단위)에서 결정 → 이 화면은 표시만(편집 불가). 전체 레벨 공통 적용.
수정하려면 상단 [S11 마진관리 티켓 탭 →] 링크로 이동. 마진율 -49~+100 정수, 소수점 버림.
10
[표] 판매가 (= 입금가 + 마진)
고객 청구가. 값 형식: NN,NNN원(강조). 데이터 성격: 자동 계산(입금가+마진, floor). 예: 65,000 × 10% = 71,500 / 48,000 × 10% = 52,800.
→ 프런트: 상품 카드·상세 가격
11
[표] 취소 시점
환불 판정 기준 시점. 값: 사용종료일 이전 / 사용종료일 이후 / 사용 완료 후. 데이터 성격: 오픈형 고정 규칙(읽기전용, 편집 불가). 사용종료일은 연결 스펙의 use_end_date에서 자동.
오픈형은 이용일이 없어 이용일 기준 다구간을 쓰지 않음 — 이 3행 규칙이 정책상 자동 적용(v0.13 8.2절).
12
[표] 쿠폰 상태
해당 시점의 쿠폰 상태. 값: 미사용(SOLD) / 사용됨(USED). 데이터 성격: 규칙 표시(읽기전용). 상태별로 환불 가능 여부가 갈림.
13
[표] 환불
환불 결과. 값: 전액 환불(사용종료일 이전 & 미사용) / 환불 불가(종료일 이후 또는 사용완료). 데이터 성격: 규칙 표시(읽기전용).
→ 고객 안내: "사용기간 종료일까지 미사용 시 전액 환불"
14
④ 썸네일 (상품은 썸네일만 소유 · A안)
상품 목록·검색결과·브릿지 카드·메인 추천에 쓰는 대표 이미지(첫 장 대표). 데이터 성격: 어드민 업로드 → 스토리지 URL 저장(base64 아님).
콘텐츠 소유(A안): 히어로·개요·상세설명·이용안내·정책·위치는 카테고리(S17)가 소유, 상품은 썸네일만. 상품별 히어로·상세정보 탭 폐지(중복 방지).
→ 프런트: 검색결과·브릿지·메인 추천 카드 썸네일
15
저장 (유효성 검사)
필수: 상품명 EN · 카테고리 1뎁스 · 연결 스펙. 판매종료일 ≥ 시작일. 누락/오류 시 저장 불가 + 탭1로 이동해 오류 메시지 표시.
저장 성공 시 alert("저장되었습니다") 후 목록(S14-A)으로 이동. 취소정책은 오픈형 고정이라 별도 입력 검증 없음.
