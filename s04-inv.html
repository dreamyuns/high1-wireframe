화면 주석 — S04-INV 재고 관리

1
[재고 동기화] 버튼 (API 4)
[PMS연동 모드]: 상품 등록 후 최초 1회 [재고 동기화] 수동 버튼 클릭 필수 → 이후 배치 자동 업데이트로 AVLB_RM_CNT / OPER_RM_CNT / RSV_CNT 갱신. 배치 실패 시 수동 버튼으로 fallback. 마지막 동기화 시각 표시.
API 4 요청: SRCH_FROM_DT / SRCH_TO_DT (현재 표시 범위 기준).
[수기 모드]: API 4 호출 없음. OPER_RM_CNT(총 운영 객실수) 관리자 직접 입력. [재고 동기화] 버튼 미표시.
요금 동기화(API 3)는 별도 버튼(⑦) — 재고 동기화와 분리 운영.
API 4 SELL_ITM_AMT 무시 확정 (하이원 2026-05-27). 재고 3값(AVLB_RM_CNT·OPER_RM_CNT·RSV_CNT)만 사용.
2
일괄 적용 패널
날짜 범위 + 총재고·컷오프·최소박·최대박 지정 후 [일괄 적용] → 범위 내 전체 행에 동일한 값 적용.
3
Sold out 행 (AVLB_RM_CNT = 0)
잔여 재고 0인 날짜: 행 분홍 + "Sold out" 표시.
프런트: 해당 날짜 체크인 상품 예약 불가.
→ 프런트: 상품 카드 / 달력 해당 날짜 "SOLD OUT" 배지 또는 비활성.
4
PMS 마감 (API 5 CLSE_YN = Y)
CLSE_YN=Y: 노란 "PMS 마감 ⚠️" 배지. 체크인 불가(checkin_allowed=false).
재고가 남아있어도 PMS 마감이 우선. 배지 호버 시 상세 툴팁.
CLSE_YN 조회: API 5 (S06-A/B/C 진입 시). S04-INV에서는 참고 표시.
5
행 인라인 수정
[수정] 클릭 → 해당 날짜 아래 인라인 편집 패널 펼침.
PMS연동 모드: AVLB_RM_CNT 참고 표시 + 수동 보정 입력 가능.
저장 시 변경이력 기록 (일시·변경자·변경 전/후).
6
[+ 행 추가] 버튼
버튼 클릭 → 테이블 맨 위에 전 컬럼 빈(null) 행 삽입. 날짜 포함 모든 필드 인라인 직접 입력.
[저장] 클릭 시 날짜 기준 정렬. [삭제] 클릭 시 행 제거.
PMS연동 모드에서도 수동 행 추가 가능 (이후 [재고 동기화]로 덮어쓸 수 있음).
7
[요금 동기화] 버튼 (API 3) — v0.2 추가
v0.2: 재고·요금을 객실 타입(RM_TYP_CD) 단위로 함께 관리. 요금(입금가)은 API 3(SELL_ITM_AMT)에서 동기화.
[요금 동기화] 클릭 → 날짜별 입금가 갱신. 재고 동기화(API 4)와 버튼 분리. 확인 팝업 후 실행.
요금 관리 주체 = 이 화면(객실 타입 단위). 상품(S06-B/C)에서는 요금 읽기전용 표시(후속 반영 예정).
8
입금가 / 판매가 (날짜별) — v0.2 추가
입금가: 호텔 납부 원가. PMS 연동 시 API 3 동기화 / 수기 시 직접 입력.
판매가: 입금가 + 마진(S11 객실 타입 기본 마진 또는 상품 개별 마진). 자동 계산, 읽기전용(회색).
→ 프런트: 판매가만 노출(입금가 미노출). 날짜별 차등 요금 반영.
마진은 S11(객실 타입 단위), 소수점 버림(floor). 판매가 = 입금가 + 마진금액(권장) 또는 입금가 × (1+마진율).
