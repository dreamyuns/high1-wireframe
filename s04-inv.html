화면 주석 — S04-INV 재고·요금 관리

1
위치 — 객실(S04) 내 [재고·요금] 탭
재고·요금은 객실 등록·수정(S04) 화면의 [재고·요금] 탭으로 진입한다. 객실 타입(RM_TYP_CD) 단위로 관리되며, 같은 타입을 참조하는 모든 상품(S06)이 이 재고·요금을 공유·읽기전용 참조한다.
2
[재고·요금 동기화] 버튼 (1개 · 재고+요금 함께)
클릭 시 PMS에서 재고(API 4)와 요금(입금가, API 3)을 한 번에 동기화한다(버튼 1개로 통합). 상품 등록 후 최초 1회 수동 필수 → 이후 배치 자동 업데이트, 배치 실패 시 fallback. 마지막 동기화 시각 표시.
신규 객실은 저장 후 동기화 가능. 재동기화 시 기존 강제 마감(판매 OFF) 상태는 보존된다.
동기화 범위(프로토타입): 2026-07-01 ~ 08-31, 재고 30. 입금가 = RM_TYP_CD별. API 4 SELL_ITM_AMT 무시(하이원 확인) — 재고 3값만 사용.
3
판매 ON/OFF 주의 배너
판매 ON/OFF는 즉시 반영되지 않고 [판매 ON/OFF 저장] 클릭 시 일괄 반영된다(민감 항목). 마감(OFF) 시 해당 일자 예약이 즉시 차단되고, 이 객실에 연결된 모든 상품에 적용됨을 경고.
4
[판매 ON/OFF 저장] 버튼
체크박스로 변경한 일자별 판매 ON/OFF를 저장한다. 저장 전 확인 팝업("강제 마감 N건 · 연결 상품 전체 차단, 진행할까요?"). 저장 시 변경이력 기록.
→ 프런트: OFF(마감) 일자는 예약 불가, 재고 0은 자동 SOLD OUT.
5
판매상태 (자동 판정)
SOLD OUT: 잔여(AVLB) = 0 (분홍 행) · 마감(강제): 판매 OFF(closed=true, 노랑 행) · 판매중: 그 외.
재고가 남아있어도 판매 OFF가 우선(강제 마감).
6
입금가 (조회 전용)
호텔 납부 원가. PMS API 3 동기화로 채워지는 조회 전용. 판매가·마진은 이 화면에 노출하지 않는다 — 판매가는 프런트 노출 시 마진(마진 마스터 S11)을 더해 계산.
SELL_AMT(예약 API 6)는 입금가(원가)로 전송. 마진 미포함.
7
판매 ON/OFF (체크박스)
체크=판매중(ON), 해제=강제 마감(OFF, closed=true). CLSE_YN 개념. 기존 '체크인허용'을 대체. 변경 후 [판매 ON/OFF 저장] 필요.
