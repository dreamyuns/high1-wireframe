화면 주석

1 2탭 구조 — 각 탭 독립 등록 폼
객실유형/침대유형 독립 CRUD. 각 탭의 [+ 등록] 버튼은 전용 등록 폼으로 이동.
· 객실유형: s09-roomtype-form.html (숙소 선택 필수)
· 침대유형: s09-bedtype-form.html
RM-MST-01: 2탭 구조(객실유형·침대유형). 각 탭 독립 CRUD. 등록·수정은 각 전용 폼 사용.
v0.6: 객실특징(RoomFeature) 탭 전면 폐기 — 정책서 10절. 객실은 객실유형·침대 구성만 관리.
2 코드
객실유형: RT-###, 침대유형: BT-### 형식. 시스템 전체 고유 자동 채번. 수정 불가. 내부 식별자.
3 이름
plain string(한국어). 객실유형 이름은 숙소 간 중복 허용 (코드로 구분). 침대유형 이름은 프런트에 직접 노출됨.
→ 객실유형: 객실 등록 폼 선택지 (카드 미노출·필터 전용) / → 침대유형 이름: 상품 카드 '침대: 킹 1개' 텍스트 / Room Detail 침대 정보
4 수정·삭제
수정: 각 탭 전용 폼으로 이동. 삭제: 연결된 객실·상품이 있으면 삭제 불가 — 연결 항목을 먼저 미노출 처리하거나 삭제 후 진행. 연결 없을 때만 확인 다이얼로그 후 삭제.
침대유형 이름 변경 시 프런트 상품 카드·Room Detail 침대 표기명도 즉시 변경됨. 주의 필요.
삭제 불가 시 안내: "연결된 항목이 N개 있습니다. 연결 항목을 먼저 미노출 처리하거나 삭제 후 진행하세요."
5 숙소 컬럼·필터 (객실유형 탭 전용)
객실유형은 숙소(Place)별로 분류 관리됨(프런트 검색 필터·정보 노출용).
목록 상단 숙소 드롭다운으로 필터링 가능. 기본: 전체 표시.
v0.2: PMS 코드 컬럼 삭제 — RM_TYP_CD는 객실관리(S04) PMS 동기화로 획득하며 객실유형 마스터에서는 관리하지 않음.
동일한 유형명(예: "스탠다드")이 여러 숙소에 존재 가능. 코드(RT-###)로 구분.

침대유형 (BedType) — 프런트 직접 노출
코드 체계: BT-###. 킹·퀸·더블·트윈·싱글·소파베드 등. 객실 등록 폼에서 침대구성(bed_rows)을 구성할 때 사용되며, 이름이 프런트 상품 카드·Room Detail 모달에 그대로 표시됨.
이름 변경 시 해당 BedType을 참조하는 모든 객실의 프런트 표시명이 즉시 변경됨. 삭제 시 연결된 객실이 있으면 삭제 불가 — 연결 객실을 먼저 미노출 처리하거나 삭제 후 진행.
