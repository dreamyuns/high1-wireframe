화면 주석

1
기본 정보 — 다국어
타이틀·서브타이틀 KO/EN 각각 입력. EN 미입력 시 KO 대체. 타이틀 KO 필수.
공통 다국어 규칙: 이 화면의 모든 텍스트 입력 필드(타이틀·서브타이틀·버튼명 등)는 KO·EN 별도 입력을 제공한다. EN 미입력 시 KO 대체 표시.
→ 프런트: 섹션 상단 타이틀·서브타이틀 텍스트
2
노출 여부
OFF 시 기간·객실 설정과 무관하게 섹션 전체 프런트 미노출.
3
노출 기간
미설정 시 상시 노출. 종료일 자정 경과 시 자동 미노출.
4
카테고리 설정 — 개요
1뎁스(카테고리) → 2뎁스(숙소) → 3뎁스(객실) 순으로 노출 범위 결정.
1뎁스만 선택: 해당 카테고리 전체 객실 노출.
2뎁스 선택: 선택된 숙소의 객실만 노출.
5
1뎁스 — 체크박스 (복수 선택)
Hotel / Condo 중 1개 이상 필수 선택.
Hotel만: hotel 하위 숙소만 2뎁스 목록에 표시.
Condo만: condo 하위 숙소만 표시.
둘 다: hotel + condo 하위 숙소 전체가 2뎁스에 합산 표시.
1뎁스 둘 다 미선택: 2뎁스 숙소 목록 영역 숨김 (폼 미표시). 1개 이상 선택 시 표시.
1뎁스 추가 체크 시: 기존 2뎁스 선택 유지 + 새 카테고리 숙소 목록 추가.
1뎁스 해제 시: 해당 카테고리 숙소 체크 자동 해제 + 수동 선택 객실 중 해당 숙소 소속 객실 자동 제거.
6
2뎁스 — 숙소 복수 선택
1뎁스 1개 이상 선택 시에만 이 영역 표시. 1뎁스 미선택 시 숨김.
복수 선택 가능.
2뎁스 숙소 미선택(전체): 1뎁스에서 선택한 카테고리 전체 숙소의 객실 노출.
2뎁스 숙소 선택 시: 선택한 숙소의 객실만 노출.
→ 프런트: 선택된 숙소 기준으로 카드 범위 결정
7
탭 분리 (2뎁스 탭)
2뎁스 2개 이상 선택 시 활성 가능.
ON: 프런트 섹션에 숙소별 탭으로 분리 표시.
   → 선택된 숙소 2개 이상: [전체] 탭 + 숙소별 탭 순서로 표시.
   → 선택된 숙소 1개: 탭분리 자동 OFF (탭 없이 통합 그리드).
OFF: 탭 없이 통합 그리드.
2뎁스 1개 선택 시 자동 OFF.

어드민 팝업 선택 최대 개수: 탭분리 ON/OFF 무관하게 총 10개 유지.
→ 프런트: 섹션 내 가로 탭 UI. [전체] 탭은 선택된 숙소 2개 이상일 때만 추가.
8
객실 선택 방식 — 자동 vs 수동
자동: 1·2뎁스 조건에 맞는 객실 중 정렬 기준 상위 최대 10개 자동 선택. 객실 추가·순위 변동 자동 반영.
수동: 관리자가 [객실 선택] 버튼으로 직접 선택·순서 지정. 최대 10개.
9
정렬 기준 (자동 선택 시)
가격순: 배치 최저가(30일 이내) 낮은 순.
A-Z / Z-A: 객실명 알파벳 순.
인기순: 최근 30일 예약수. 데이터 없으면 등록순 폴백.
인기순 선택 시 "(최근 30일 예약수 기준, 데이터 부족 시 등록순)" 안내 표시.
10
[객실 선택] 버튼 — 팝업 진입
클릭 시 B. 객실 선택 팝업 오픈 (아래 섹션 참조).
버튼 옆 "선택됨: N / 10"으로 현재 선택 수 상시 표시.
11
선택된 객실 목록
팝업에서 [적용] 후 표시. 형식: 숙소명 — 객실명 , 기준N-최대N , Nm².
인원·면적 미등록 시 해당 항목 생략 (순차적 폴백).
프런트 카드 노출 순서는 순서(order) 필드 값 기준으로 정렬(≡ 핸들 드래그 재정렬은 향후 적용 예정).
[제거] 클릭 시 목록에서 즉시 제거 (카운터 감소).

최대 개수: 탭분리 ON/OFF 무관하게 전체 합산 10개 고정.
탭분리 ON이어도 개별 숙소 제한 없음. 10개를 어느 숙소 조합으로 선택해도 무방.
HIDE 상태인 객실은 팝업 목록에서 표시 안 됨. 이미 선택된 객실이 이후 HIDE로 변경되면 목록에 경고 배지 표시 권장.
→ 프런트: 이 목록 순서대로 카드 그리드에 노출 (탭분리 ON 시 숙소별 탭 + [전체] 탭)
12
전체보기 버튼
사용 ON 시 섹션 우측 상단(또는 하단)에 버튼 노출.
버튼명 KO 필수. EN 미입력 시 KO 대체 표시.
링크 URL: 내부 경로(/...) 또는 외부 URL(https://) 모두 허용. 외부 URL은 새 탭(_blank) 이동.
버튼명 KO와 링크 URL은 사용 ON 시 필수. 미입력 시 저장 차단.
→ 프런트: 섹션 타이틀 우측 또는 카드 그리드 하단에 버튼 노출
S12-C 객실 선택 팝업 (B. [객실 선택] 버튼 클릭 시)
좌측 숙소 클릭 → 우측 객실 목록 전환. 체크 상태는 숙소 이동 후에도 유지.

취소 적용

팝업 주석

13
객실 선택 팝업 — 개요
2뎁스에서 선택한 숙소 기준으로 객실 목록 제공.
좌측(숙소) 클릭 → 우측(객실 목록) 전환. 탐색 전용이며 좌측엔 체크박스 없음.
숙소별 선택된 객실 수를 숙소명 옆 배지로 표시.
14
선택 카운터 (N / 10)
우측에서 객실 체크/해제 시 실시간 업데이트.
카운터는 전체 합산 기준 N / 10. 탭분리 ON/OFF 무관.
10개 선택 완료 시 미선택 객실의 체크박스 비활성화(disabled) + "최대 선택 완료" 툴팁.
15
[적용] 버튼
팝업 닫힘 + 현재 선택 상태를 폼의 "선택된 객실 목록"에 반영.
취소(✕ 또는 [취소] 버튼) 클릭 시 변경 사항 미반영, 이전 목록 유지.
팝업에서 아무것도 선택 안 한 상태로 [적용] 클릭 시 목록이 비어있음. 저장 시 유효성 검사: 수동 선택 모드에서 선택된 객실 0개 → 저장 불가 경고.
16
좌측 숙소 목록
2뎁스에서 선택된 숙소만 표시. 미선택(전체)이면 1뎁스 하위 전체 숙소 표시.
클릭한 숙소: 진한 배경(active) + 좌측 초록 보더 표시.
숙소명 옆 배지: 해당 숙소에서 선택된 객실 수.
17
우측 객실 목록
좌측에서 선택한 숙소의 객실 목록(노출여부 SHOW인 객실만).
행 형식: 객실명 , 기준N-최대N , Nm² (1행 콤마 구분).
면적 미등록 시 "기준N-최대N"만 표시. 인원·면적 미등록 시 객실명만 표시.
체크된 행: 초록 배경으로 선택 상태 시각화.
다른 숙소로 이동했다가 돌아와도 체크 상태 유지.
HIDE 상태 객실은 목록에서 제외. 객실 등록(S04)에서 SHOW인 것만 표시.
인원·면적 데이터 출처: S04 어드민 직접 입력 (PMS 미제공).
