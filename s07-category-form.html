화면 주석

1 카테고리 코드
PLACE 도메인은 plc00001~, ROOM 도메인은 rmc00001~ 순번으로 자동 채번. 수정 불가. 등록 후 변경 없음.
코드는 내부 식별자. 시설(facility)의 category_id 참조키로 사용됨.
2 구분 (읽기 전용)
도메인(PLACE/ROOM)은 폼에서 선택하지 않는다. 어떤 목록에서 [등록]을 눌렀는지(진입 경로)에 따라 자동으로 정해진다. 숙소 시설 카테고리 목록 → PLACE, 객실 시설 카테고리 목록 → ROOM. 화면에는 읽기 전용으로만 보인다.
등록 후 도메인 변경 불가. 잘못 등록 시 삭제 후 올바른 목록에서 재등록. 코드 접두어도 도메인에 따라 plc/rmc로 자동 결정됨.
3 카테고리명 (EN 필수 · ZH 선택)
영문(EN)은 반드시 입력해야 하며, 비워두면 저장되지 않는다. 중문(ZH)은 선택 입력이고 비워두면 프런트에서 영문으로 대신 보인다. 한국어(국문)는 사용하지 않는다(외국인 전용 사이트). 이름을 바꾸면 프런트 표시명도 바로 바뀐다.
→ 프런트: 숙소 레이어 > 안내정보 탭 시설 카테고리 헤더 / Room Detail 시설 그룹 헤더
프로토타입 후속 반영 예정: 현재 프로토타입은 명칭이 국문 + 영문(선택) 구조. 정책 목표(EN 필수 · ZH 선택)를 화면기획서에 선반영한 것.
4 픽토그램 이미지
카테고리를 시각적으로 구분하기 위한 아이콘 이미지. 선택 사항이며 미입력 시 기본 아이콘으로 대체. PNG 또는 SVG, 1:1 비율, 100KB 이하 권장.
현재 프런트(v0.4)에서는 픽토그램 미사용. 실서비스 UI에서 카테고리 헤더 아이콘으로 활용 예정.
5 노출 여부
Y: 숙소·객실 시설 피커에서 표시. N: 피커에서 숨김(이미 연결된 시설은 유지).
노출 N 처리 시 해당 카테고리의 시설이 프런트에서도 미노출될 수 있음. 확인 필요.
