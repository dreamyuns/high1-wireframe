화면 주석

1 시설 코드
영문 대문자, 수동 입력, 중복 불가. 등록 후 수정 불가. 내부 식별자로만 사용.
코드는 등록 후 수정 불가. 잘못 입력 시 삭제 후 재등록 필요. 프런트에는 미노출.
2 도메인 선택
PLACE: 숙소 등록 Step5 시설 피커에서 사용. ROOM: 객실 등록 시설 피커에서 사용. 도메인에 따라 카테고리 선택지가 자동으로 필터링됨.
도메인 변경 불가 정책. 등록 후 변경 시 삭제 후 재등록 필요.
3 카테고리 연결
선택된 도메인과 동일한 도메인의 카테고리만 표시. 다른 도메인 카테고리 선택 불가.
→ 프런트: 시설 카테고리별 그룹핑에 사용됨. 해당 카테고리명이 그룹 헤더로 표시.
4 시설명
plain string(한국어). 이름 변경 시 해당 시설을 facility_ids에 포함한 모든 숙소·객실의 프런트 표시명이 즉시 변경됨.
→ 프런트: 숙소 레이어 시설 목록 / 상품 카드 시설 칩 / Room Detail 시설 목록에 직접 표시
5 노출 여부
Y: 시설 피커 목록에 표시. N: 피커에서 숨김(이미 선택된 시설은 그대로 유지).
N으로 변경해도 이미 facility_ids에 포함된 데이터는 삭제되지 않음. 프런트 렌더링 영향 별도 확인 필요.
