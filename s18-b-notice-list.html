공통정책 — 공지 1개 = 두 곳 노출
하나의 공지가 ① 마이페이지 공지 목록/상세(로그인 필요)와 ② 프런트 팝업(대상 페이지, 로그인 없이) 두 곳에 동시에 쓰입니다. 제목·본문을 공유하므로 따로 관리하지 않습니다.
안내 문구는 EN 필수 · ZH 선택(ZH 미입력 시 EN 대체).
정렬 = 수정일 최신순(수동 순서/고정 없음). 근거: 프로토타입 admin v0.7.31 · 개발사 기능가이드.
1
[+ 공지 등록]
클릭 시 공지 등록 화면(S18-C)으로 이동합니다. 목록의 행 [수정]도 동일 화면(수정 모드)으로 진입합니다.
2
상태 — 게시중 / 대기·종료 / 미게시
게시중 = 게시 ON + 현재 시각이 게시기간 내 · 대기/종료 = 게시 ON이지만 시작 전이거나 종료 경과 · 미게시 = 게시 OFF(초안).
→ 프런트: 게시중 공지만 고객에게 노출됩니다.
3
팝업(대상) — ON/OFF + 대상 페이지
팝업 사용 시 ON 배지 + 대상 페이지 배지(M=메인 · S=검색결과 · P=숙소상세)를 표시합니다. 미사용은 OFF.
→ 프런트: 해당 페이지 진입 시 팝업 노출(페이지당 최신 공지 1개, 닫기/24시간 숨김).
4
작업 — 수정 / 삭제
수정 → S18-C(수정 모드). 삭제 → 확인 후 삭제. (저장키 high1_notices_v1)
