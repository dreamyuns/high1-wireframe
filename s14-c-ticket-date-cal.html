탭2 · 날짜 설정 1
기준: 프로토타입 admin v0.7.31
· 날짜 방식 = 오픈형 고정. 사용기간 안에서 자유 사용(이용일 미지정). 현재 운영 방식.
· 오픈형은 날짜별 한도·입금가 설정이 없다. 사용기간은 스펙(사용시작/종료일)을 표시용으로만 쓰고 날짜 유효성 체크는 하지 않는다.
· 커트오프(예약 마감)는 이용일 기준이라 이용일이 없는 오픈형에는 적용되지 않는다. 날짜지정형에서만 설정.
· 날짜지정형(날짜별 한도·입금가·커트오프)은 정책상 기능 유지이나 현재 프로토타입 범위 밖(추후 필요 시 사용).

날짜 방식 2

오픈형 (고정) 사용기간 내 자유 사용 — 현재 운영 방식
날짜지정형 (미사용) 날짜별 한도·입금가·커트오프 — 기능 유지·현재 프로토타입 범위 밖 4
오픈형은 날짜별 한도·입금가 설정이 없습니다. 사용기간은 스펙(사용시작/종료일)을 표시용으로만 사용하며 날짜 유효성 체크는 하지 않습니다.

커트오프 (예약 마감) 3

커트오프는 이용일 기준 마감이라 이용일이 없는 오픈형에는 적용되지 않습니다. 날짜지정형에서만 "이용일 N일/시간 전 HH:MM까지" 형태로 설정합니다.
· 오픈형이 기본·우선 운영 · 날짜별 한도·입금가·커트오프는 오픈형에선 비활성 · 날짜지정형 전환 시에만 활성(현재 프로토타입 미구현).

화면 주석

1
탭2 · 날짜 설정
S14-B 상품 폼의 탭2. 같은 상품의 날짜 방식·커트오프를 관리한다(탭1은 기본정보·레벨/판매가·취소정책·썸네일).
저장은 탭1과 공통. 오픈형에서는 이 탭에 실제 편집 항목이 없다(안내 위주).
2
날짜 방식 (오픈형 고정)
데이터 성격: 고정값(오픈형). 값: 오픈형(고정) — 사용기간 내 자유 사용, 이용일 미지정. 프로토타입은 오픈형만 운영하며 방식 전환 UI가 없다.
오픈형은 날짜별 한도·입금가가 없고, 사용기간은 스펙(사용시작/종료일)을 표시용으로만 사용(날짜 유효성 체크 없음).
→ 프런트: 이용일 선택 없이 사용기간 내 사용 안내
3
커트오프 (오픈형 미적용)
예약 마감 기준. 데이터 성격: 날짜지정형 전용(오픈형 비활성). 커트오프는 이용일 기준 마감이라 이용일이 없는 오픈형에는 적용되지 않는다.
날짜지정형에서만 "이용일 N일/시간 전 HH:MM까지" 형태로 설정. 미설정 시 이용일 당일 자정까지 구매 가능.
4
날짜지정형 (기능 유지 · 현재 미사용)
고객이 이용일을 골라 구매하고 날짜별 한도·입금가·커트오프를 두는 방식. 정책상 기능은 유지되나 현재 프로토타입 범위 밖(구현·노출 안 함).
추후 날짜지정형이 필요해지면 이 탭에 달력·날짜별 한도·입금가·커트오프 UI가 활성화된다.
