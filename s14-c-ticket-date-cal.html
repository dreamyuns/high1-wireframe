화면 주석

1
탭2 — 날짜 설정
날짜 관련 설정(방식·한도·날짜별 입금가·커트오프)을 한 곳에 모음. 탭1(마스터)과 같은 상품을 편집.
날짜 영역을 마스터에서 분리해 폼 비대화 방지. 숙소 S06(마스터/인벤토리) 패턴과 동일 사상.
2
날짜 방식
오픈형: 날짜 미지정, 사용기간 내 자유 사용. 날짜지정형: 고객이 이용일 선택 후 구매, 날짜별 한도·입금가 적용.
3
상품 정보 노출 (카테고리·사용기간)
탭1에서 선택한 카테고리·사용기간만 간결 표시(편집 불가). 연결 스펙 미선택 시 각 값은 -로 표시.
사용기간(스펙)이 달력의 입력 가능 범위가 됨. 기간 외 날짜는 '기간외' 비활성.
4
오픈형 선택 시 동작
달력 영역이 숨겨지고 커트오프만 남는다. 가격은 S14-B 기본 입금가·판매가 적용(날짜별 조정 없음). 한도 개념도 없음.
5
날짜별 입금가·한도 — 사용기간 기준 노출
달력은 사용기간만큼 월 단위 노출(7/10~8/30 → 7·8월). 셀에 판매가(대인 기준) + 한도 표기. 기간 외 날짜는 비활성.
입금가를 조정한 날짜는 색상(노랑)으로 구분. 미조정 날짜는 S14-B 기본 입금가 상속. 한도: ∞ / 숫자(잔여 0 자동매진) / 0(직접 매진).
→ 프런트: 날짜 선택 캘린더의 날짜별 가격·잔여/매진 표시
6
셀 표기 규칙
달력 셀은 공간상 판매가(대인 기준) + 한도만 표기. 레벨별(대인/소인) 가격은 셀 클릭 시 우측 편집 패널에서 확인·수정.
7
날짜 입금가·한도 편집 패널
선택 날짜의 레벨별 입금가를 입력(미입력 시 기본값 상속) → 판매가 자동 계산(입금가 + 마진). 한도(∞/숫자/0)도 함께 설정. [적용] → state 반영, 하단 [저장]에서 최종 기록.
판매가 = 입금가 + 마진(S14-B 고정 마진율). 마진은 날짜 무관 상품 고정. 날짜별로 바뀌는 건 입금가(숙소 S06 방식).
8
구간 일괄 적용
여러 날짜를 선택(드래그)해 동일 입금가·한도를 한 번에 적용. 성수기 등 장기간 동일 설정 시 사용.
9
커트오프 (예약 마감)
이용일 기준 N일/N시간 전 + 기준 시각(HH:MM). 미설정 시 이용일 당일 자정까지. 오픈형·날짜지정형 공통.
→ 프런트: 커트오프 경과 시 해당 날짜/상품 '구매 마감' 처리
10
저장
날짜 방식·날짜별 입금가/한도·커트오프를 상품에 저장. 탭1(마스터)과 같은 상품의 날짜 영역만 기록.
★미결: 티켓 입금가는 본래 스펙(High1 납부 원가) 고정값. 날짜별 입금가 조정의 정책적 의미(실제 납부액 관계)는 대화창1 확인 대상. / 날짜지정형 한도 미설정 날짜 기본값(∞ vs 판매불가)도 미결.
