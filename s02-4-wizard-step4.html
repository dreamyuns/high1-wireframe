1
숙소 안내 HTML (guide_html — EN 필수 / ZH 선택)
숙소의 체크인·체크아웃 절차, 주요 시설 이용 안내, 주의 사항 등을 HTML로 입력한다. 영문(EN)은 필수, 중문(ZH)은 선택이다. 중문 미입력 시 프런트 중문 모드에서 영문이 대체 표시된다. (한국어 입력칸 없음)
이미지 Ctrl+V 붙여넣기 시 Data URL(base64) 형식으로 저장된다. 현재 UI는 단순 textarea이나 실서비스에서 WYSIWYG 에디터로 교체 예정이다.
→ 프런트: 숙소 레이어 > 안내정보(Guide) 탭 상단 HTML 렌더링
저장 필드: guide_html(EN) · guide_html_zh(ZH). 프로토타입 후속 반영: 현재 프로토타입은 guide_html(국문)+guide_html_en 구조. EN 필수·ZH 선택으로 교체 필요.
2
정책 안내 HTML (policy_html — EN 필수 / ZH 선택)
취소·환불 정책, 반려동물·흡연 정책, 체크인 시간 외 조기/지연 입실 정책 등을 입력한다. 영문(EN)은 필수, 중문(ZH)은 선택이다. 중문 미입력 시 영문이 대체 표시된다.
guide_html과 분리된 별도 탭으로 프런트에 표시되므로 정책과 안내 내용을 명확히 구분하여 입력한다. HTML 형식을 지원하며 이미지 붙여넣기도 가능하다.
→ 프런트: 숙소 레이어 > 정책정보(Policy) 탭 HTML 렌더링
저장 필드: policy_html(EN) · policy_html_zh(ZH). 프로토타입 후속 반영: 현재 policy_html(국문)+policy_html_en 구조. EN 필수·ZH 선택으로 교체 필요.
3
AI 번역 버튼 (미입력 EN/ZH 자동 채움)
버튼을 누르면 숙소 안내·정책 안내·추가요금 안내의 비어 있는 다국어 칸을 자동으로 채운다. 영문(EN)이 있고 중문(ZH)이 비어 있으면 중문을, 반대의 경우 영문을 자동 번역해 넣는다. 이미 입력된 칸은 덮어쓰지 않는다.
프로토타입은 미입력 칸을 원문 그대로 복사하는 더미 동작이며, 실서비스에서 번역 API로 교체 예정이다.
저장 전 항상 EN 필수값을 재검증한다. AI 번역으로도 EN이 채워지지 않으면 저장 불가.
4
이미지 붙여넣기 용량 경고
HTML textarea에 이미지를 붙여넣으면 base64 Data URL로 변환되어 원본 이미지보다 약 33% 더 큰 텍스트 데이터로 저장된다. 여러 이미지를 붙여넣을 경우 localStorage 용량이 빠르게 소진되므로, 외부 이미지 URL 방식 사용을 권장한다. 이 경고는 항상 표시되어 입력 전에 사용자가 인지할 수 있도록 한다.
실서비스에서는 이미지 업로드 파이프라인(CDN) 구축 후 URL만 저장하도록 변경 필요.
5
추가요금 안내 (extra_fee_notes) — v0.2 신설
기존 객실(S04)의 '부가요금 설정'을 이 숙소 화면으로 옮긴 항목입니다. 예전에는 객실마다 "1인당 30,000원(현장 결제)" 같은 결제와 연결된 값이었지만, 이제는 결제와 아무 관련이 없는 안내용 글로 바뀌었습니다. 즉 여기 입력한 금액은 실제로 계산·청구되지 않고, 고객에게 "이런 추가요금이 있어요"라고 알려주기만 합니다.
입력 방법: 한 줄에 하나씩 자유롭게 적습니다. (예: Extra bedding: KRW 15,000 per set / night) [+ 항목 추가] 버튼으로 줄을 늘리고, 각 줄의 [삭제] 버튼으로 지웁니다.
언어 규칙: 각 줄마다 영어(EN)는 반드시 입력해야 저장됩니다. 중국어(ZH)는 선택이며, 비워두면 고객 화면에 영어가 대신 보입니다. (한국어 입력칸 없음 — 외국인 전용 사이트)
→ 프런트: 숙소 레이어 > 정책정보(Policy) 탭, '정책 안내' 아래 '추가요금(Extra Fees)' 블록에 입력한 줄들이 목록(•)으로 표시됨.
저장 필드: extra_fee_notes (배열). 각 항목 { en(필수), zh(선택) }. EN 미입력 행이 있으면 저장 불가(유효성 검사). 빈 배열이면 프런트 '추가요금' 블록 자체를 숨김.
