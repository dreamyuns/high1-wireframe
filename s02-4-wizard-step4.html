화면 주석

1
숙소 안내 HTML (guide_html)
숙소의 체크인·체크아웃 절차, 주요 시설 이용 안내, 주의 사항 등을 HTML로 입력한다. 이미지 Ctrl+V 붙여넣기 시 Data URL(base64) 형식으로 저장된다. 현재 UI는 단순 textarea이나 실서비스에서 WYSIWYG 에디터로 교체 예정이다.
→ 프런트: 숙소 레이어 > 안내정보(Guide) 탭 상단 HTML 렌더링
2
정책 안내 HTML (policy_html)
취소·환불 정책, 반려동물·흡연 정책, 체크인 시간 외 조기/지연 입실 정책 등을 입력한다. guide_html과 분리된 별도 탭으로 프런트에 표시되므로 정책과 안내 내용을 명확히 구분하여 입력한다. HTML 형식을 지원하며 이미지 붙여넣기도 가능하다.
→ 프런트: 숙소 레이어 > 정책정보(Policy) 탭 HTML 렌더링
3
이미지 붙여넣기 용량 경고
HTML textarea에 이미지를 붙여넣으면 base64 Data URL로 변환되어 원본 이미지보다 약 33% 더 큰 텍스트 데이터로 저장된다. 여러 이미지를 붙여넣을 경우 localStorage 용량이 빠르게 소진되므로, 외부 이미지 URL 방식 사용을 권장한다. 이 경고는 항상 표시되어 입력 전에 사용자가 인지할 수 있도록 한다.
실서비스에서는 이미지 업로드 파이프라인(CDN) 구축 후 URL만 저장하도록 변경 필요.
