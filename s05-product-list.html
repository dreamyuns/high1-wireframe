화면 주석

1
상품코드 (자동 채번)
PR-#### 형식으로 등록 시 자동 생성된다. 수정 화면에서는 읽기 전용으로 표시된다.
→ 프런트: 미노출 (내부 식별자)
2
숙소 필터
전체 또는 특정 숙소를 선택해 상품 목록을 필터링한다. 선택 변경 시 라우트가 #/products/place/:placeId 로 변경된다. 숙소 목록 또는 객실 목록에서 '상품연결 수' 링크로 진입한 경우 해당 숙소 필터가 자동 적용된다.
3
상품 유형
ROOM_ONLY(룸온리) / PACKAGE(패키지). 향후 티켓·투어 유형 추가 예정.
→ 프런트: 현재 카드에 미노출. 향후 상품 유형 라벨 표시 예정.
4
취소정책 요약
FREE_N_DAYS → 'N일 전 무료취소'. NON_REFUNDABLE → '환불불가'로 요약 표시한다.
→ 프런트: 상품 카드 취소 한 줄 텍스트 ('N일 23:59까지 무료취소 가능' / '취소 및 환불불가')
5
인벤토리 행 수
inventory[] 배열 길이로 일자별 재고·요금 입력 여부를 파악할 수 있다. 0이면 날짜 선택 시 프런트에서 'no_inv' 상태(재고 없음)가 표시된다.
6
삭제 버튼
확인 다이얼로그 후 상품 및 전체 인벤토리를 삭제한다.
실서비스에서 예약 연동 시 삭제 제한 조건 추가 정의 필요. 현재는 프로토타입이므로 삭제 제한 없음.
7
PMS 상품정보 동기화 (일괄)
현재 숙소 필터 기준으로 PMS연동 상품 전체에 대해 PMS API 3(otaHbItmInfo.do)을 호출하여 상품 정보를 일괄 갱신한다.
변경된 필드 감지 시 해당 상품 행에 '변경 감지' 배지(⑨)를 표시한다.
상품 등록 후 최초 1회 수동 동기화 필수. 이후 배치 자동 업데이트 기본. 배치 실패 시 이 버튼으로 fallback 가능.
S06-A 개별 상품의 [PMS 불러오기] 버튼과 역할 동일. 이 버튼은 목록 전체 일괄 처리용.
8
연동 모드 배지
PMS연동(파랑) / 수기(회색). 상품 등록 시 최초 1회 선택, 이후 변경 불가.
→ 프런트: 미노출 (내부 운영 구분)
9
변경 감지 배지
PMS 동기화 실행 후, PMS 원본 데이터와 어드민 저장 데이터 간 차이가 감지된 상품에 표시된다.
관리자가 S06-A 수정 화면 진입 → 변경 내용 확인 후 적용(또는 무시) 처리하면 배지가 제거된다.
노란색으로 행 전체를 하이라이트하여 주의를 유도한다.
변경 감지는 상품 정보(API 3)에만 해당. 재고·요금(API 4/5)은 S06-B/C 진입 시 자동 갱신.
10
노출 컬럼 — 배지 구분 규칙
일반 Y: 초록 배지 (admin 설정 SHOW)
일반 N: 회색 배지 (admin 설정 HIDE)
강제 N 🔒: 회색 배지 + 🔒 + 툴팁 — 연결 객실이 HIDE 상태. 행 연보라 하이라이트.
cascade 상태에서 S06-A 노출여부 select는 유지되나 경고 박스 추가 표시됨.
프런트 노출 조건: 객실SHOW AND 상품SHOW. 상세: policy-decisions.html 섹션 12.
