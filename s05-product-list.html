화면 주석

1
상품코드 (자동 채번)
PR-#### 형식으로 등록 시 자동 생성된다. 수정 화면에서는 읽기 전용으로 표시된다.
→ 프런트: 미노출 (내부 식별자)
2
숙소 필터
전체 또는 특정 숙소를 선택해 상품 목록을 필터링한다. 선택 변경 시 라우트가 #/products/place/:placeId 로 변경된다. 숙소 목록 또는 객실 목록에서 '상품연결 수' 링크로 진입한 경우 해당 숙소 필터가 자동 적용된다.
3
상품 유형
숙소 도메인은 ROOM_ONLY(룸온리) 단일. 패키지(RM+CPN)는 티켓·쿠폰 결합 상품으로 별도 라인(본 화면기획서 범위 밖).
→ 프런트: 카드 미노출.
4
투숙 시작일 / 투숙 종료일
판매기간과 별개. 고객이 체크인일로 선택 가능한 범위(정책서 15절). 목록에서 상품별 stay_start_date / stay_end_date를 컬럼으로 노출한다.
v0.6: 기존 취소정책·인벤토리(행수) 컬럼을 제거하고 투숙 시작/종료일 컬럼으로 대체(정책서 15절). ※ 투숙 가능 기간은 정책 정의, 프로토타입 후속 반영.
6
삭제 버튼
확인 다이얼로그 후 상품 및 전체 인벤토리를 삭제한다.
실서비스에서 예약 연동 시 삭제 제한 조건 추가 정의 필요. 현재는 프로토타입이므로 삭제 제한 없음.
7
PMS 상품정보 동기화 (일괄)
현재 숙소 필터 기준으로 PMS연동 상품 전체에 대해 PMS API 3(otaHbItmInfo.do)을 호출하여 상품 정보를 일괄 갱신한다.
신규 상품은 이 동기화로만 생성된다(수동 [+상품 등록] 없음). 최초 1회 수동 필수, 이후 배치 자동 업데이트, 배치 실패 시 fallback.
동기화 대상: 각 객실(rm_typ_cd)당 룸온리 상품 1건 생성/갱신. 관리자 보완 필드는 보존.
8
연동 모드 배지
PMS연동(파랑) / 수기(회색). 상품 등록 시 최초 1회 선택, 이후 변경 불가.
→ 프런트: 미노출 (내부 운영 구분)
11
[누락된 필드 AI 번역] 버튼
상품명·설명 등 미입력 영문/중문 필드를 AI 번역으로 자동 채운다(더미). PMS 동기화로 생성된 상품의 영문 상품명 등이 비어 있을 때 사용.
다국어 정책: 영문(EN) 필수 · 중문(ZH) 선택 · 국문 미사용(상품 도메인).
10
노출 컬럼 — 배지 구분 규칙
일반 Y: 초록 배지 (admin 설정 SHOW)
일반 N: 회색 배지 (admin 설정 HIDE)
강제 N 🔒: 회색 배지 + 🔒 + 툴팁 — 연결 객실이 HIDE 상태. 행 연보라 하이라이트.
cascade 상태에서 S06-A 노출여부 select는 유지되나 경고 박스 추가 표시됨.
프런트 노출 조건: 객실SHOW AND 상품SHOW. 상세: policy-decisions.html 섹션 12.
