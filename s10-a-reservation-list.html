화면 주석

1
날짜 검색 기준
예약일(예약 접수 일시)과 체크인일을 독립적으로 필터링할 수 있다. 기본값: 예약일 기준 최근 30일. 날짜 미입력 시 전체 기간 조회.
2
예약번호 채번 규칙
PMS 연동 상품: BK-YYYYMMDD-NNNNN
수기 관리 상품: HM-YYYYMMDD-NNNNN
NNNNN = 날짜별 5자리 시퀀스. 상세 채번 규칙은 예약관리 기획 시 확정.
※ BOOKING_ID(PMS API 6 전송값): BK-형식을 그대로 사용. 형식(길이·문자셋) 규칙은 PMS 담당자 확인 필요. (pms-vendor-questions.md Q10)
3
문제 예약 알림 요약
결과 목록 상단에 예약실패 / 취소요청 건수를 집계하여 pill 배지로 표시. 해당 행은 배경색으로 시각 구분(예약실패=연분홍, 취소요청=연주황).
※ 기획 결정: 별도 알림 목록 화면 없음 — 배지 표시로 운영.
4
LNB — 취소 목록
'취소 목록' 클릭 시 별도 페이지 이동 없이 상태 필터를 "취소요청 + 취소완료"로 자동 적용. LNB 배지(숫자)는 현재 처리 대기 중인 취소요청 건수. '예약 목록' 클릭 시 필터 초기화 후 전체 목록 복귀.
5
연동 유형 구분
PMS: PMS 연동 상품 예약. 취소 시 API 7 자동 처리.
수기: 수기 관리 상품 예약. 취소 시 관리자 수동 확정 필요.
6
예약 상태 정의
확정대기 수기 상품 — 관리자가 호텔 직접 확인 후 수동 확정 전
⚠ 예약실패 PMS API 6 실패 — 관리자 수동 처리 필요
예약확정 PMS 예약 성공 또는 수기 관리자 확정 완료
⚠ 취소요청 고객 취소 접수 — 위약금 확인 또는 처리 대기 중
취소완료 취소 처리 및 환불 완료
노쇼 체크인일 경과 미투숙 — 위약금 100% 적용
※ RSV_STAT_CD(PMS) 코드 매핑 상세는 예약관리 기획 시 확정 예정.
7
판매가 (목록 표시)
우리 DB 기준 판매가(입금가 + 마진) 표시. 입금가(PMS SELL_AMT)는 목록에 미표시. 취소완료·노쇼 행의 판매가는 원래 판매가 그대로 표시(환불금액은 상세에서 확인).
→ 프런트: 판매가만 노출 (입금가·마진 미노출)
8
엑셀 다운로드
추후 논의. 현 단계에서는 버튼 영역만 예약(비활성 표시).

취소 목록 뷰 주석

A
뷰 전환 방식
별도 페이지 이동 없이 S10-A 동일 화면에서 상태 필터만 변경된다.
날짜 기준 레이블: "예약일" → "취소일" 로 변경.
URL 예시: #/reservations?status=cancel-requested,cancelled
B
추가 컬럼 — 위약금·환불금액
예약 목록과 달리 취소일시 · 위약금 · 환불금액 컬럼이 추가된다.
취소요청(미처리) 상태는 위약금·환불금액 = "—"으로 표시.
위약금은 고객 청구금액(판매가 기준). 환불금액 = 판매가 − 위약금.
※ 위약금 계산: 위약금율(DLFT_APLY_AMT ÷ 입금가) × 판매가, 소수점 첫째자리 반올림.
