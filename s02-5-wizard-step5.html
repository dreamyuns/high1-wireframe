화면 주석

1
카테고리 목록 (좌측 패널)
PLACE 도메인 카테고리 목록(v0.4 시드: 편의시설·식음료·레저·스포츠). 선택된 카테고리는 파란 텍스트로 표시되며 우측에 해당 카테고리 시설 목록이 로드된다.
카테고리 전환 시 현재 체크 상태가 state에 자동 병합되어 다른 카테고리 선택값이 유실되지 않는다.
카테고리 추가·수정은 공통관리 > 카테고리관리에서 가능하다.
PL-WIZ-04: 카테고리 전환 시 현재 체크 상태 state 병합 선행 실행.
2
숙소에 적용 (facility_ids)
체크 시 해당 시설이 facility_ids 배열에 포함되어 숙소 보유 시설 전체 목록이 된다. 체크 해제 시 대표 체크도 자동 해제된다.
→ 프런트: 숙소 레이어 > 안내정보 탭 카테고리별 시설 목록
3
대표 (featured_facility_ids)
"숙소에 적용" 체크 상태에서만 활성화된다. 적용 해제 시 대표도 자동 해제. 최대 10개 제한이며 이미 10개 선택된 경우 추가 대표 체크박스가 비활성화된다.
→ 프런트: 브릿지 페이지 Overview '대표 시설' 칩 나열 (최대 10개)
4
대표 시설 노출 현황 배너
전체 카테고리에 걸쳐 현재 선택된 대표 시설 수를 실시간으로 표시한다 (N / 10). 체크박스 변경 시 즉시 갱신된다.
PR-FORM-04: 대표 시설 최대 10개 초과 시 추가 체크 비활성.
5
적용된 시설 칩 영역
체크박스 변경 시 실시간으로 갱신된다. 형식: "카테고리: 시설명". 대표 시설에는 파란 '대표' 뱃지가 부착된다.
전체 카테고리에 걸친 최종 적용 시설 목록이며, 저장 시 이 목록 기준으로 facility_ids · featured_facility_ids가 기록된다.
→ facility_ids: 숙소 레이어 안내정보 탭 시설 목록 / → featured_facility_ids: Overview 대표 시설 칩
