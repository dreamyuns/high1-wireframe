Room Detail 모달 주석 (callout ①~⑫)

1
모달 헤더 — 객실명
모달 상단 헤더 1행에 객실명을 크고 굵게 표시.
어드민 S03 객실 등록 · 객실명
h1_rooms[].room_name
모달 헤더 1행 (흰색, 굵게)
2
모달 헤더 — 상품명
헤더 2행에 상품명을 보통 굵기로 표시.
어드민 S04 상품 등록 · 상품명
h1_products[].name
모달 헤더 2행 (연한 색, 보통 굵기)
3
갤러리 이미지
좌측 갤러리에 객실 이미지를 메인 1장 + 썸네일 행으로 표시. 썸네일 클릭 시 메인 이미지 전환.
어드민 S03 객실 등록 · 이미지 등록 (images 배열)
h1_rooms[].images[]{data_url}
좌측 갤러리 (메인 + 썸네일 행)
4
Information — 객실유형 · 침대유형 · 객실특징
공통마스터에서 코드를 이름으로 변환하여 표시. 복수 선택 시 " · "으로 구분.
어드민 S03 객실 등록 · 객실유형 / 침대유형 / 객실특징 선택
어드민 S09-A/B 객실유형관리 (마스터 등록)
h1_rooms[].room_type_id → h1_room_types[].name
h1_rooms[].bed_types[]{type,count} → h1_bed_types[].name
h1_rooms[].trait_ids[] → h1_room_traits[].name
Information 목록 · 객실유형 / 침대유형 / 객실특징 행
5
Information — 인원 · 면적
기준 인원 / 최대 인원 / 면적(㎡) 표시.
어드민 S03 객실 등록 · 기준인원 / 최대인원 / 면적(㎡)
h1_rooms[].standard_occupancy · h1_rooms[].max_occupancy · h1_rooms[].area_sqm
Information 목록 · 인원 행 (기준 N명 / 최대 N명) / 면적 행
6
Information — 엑스트라베드 가능 여부
객실에 엑스트라베드 추가 가능 여부와 최대 개수를 표시. 불가 시 해당 행 미표시.
어드민 S03 객실 등록 · 엑스트라베드 허용 여부 / 최대 수량
h1_rooms[].extra_bed_allowed (boolean) · h1_rooms[].extra_bed_max
Information 목록 · 엑스트라베드 행 (허용 시만 표시)
7
섹션 네비 — 상품안내 / 정책 / 객실시설
Information 아래 섹션 전환 버튼. 각 탭 클릭 시 해당 데이터를 아래 콘텐츠 영역에 렌더링.
어드민 S04 상품 등록 (상품안내·정책) / S03 객실 등록 (시설)
h1_products[].guide_policy_html · h1_rooms[].facility_ids
섹션 탭 버튼 (상품안내 / 정책 / 객실시설)
8
상품 안내 HTML
상품안내 탭에 innerHTML로 렌더링. 포함 항목·이용 조건·주의사항 등 상세 안내.
어드민 S04 상품 등록 · 안내/정책 HTML textarea
h1_products[].guide_policy_html
상품안내 섹션 콘텐츠 (innerHTML)
XSS 주의. 실서비스 배포 시 새니타이저 필수 적용.
9
추가 요금 (extra_charges)
정책 섹션에 추가 인원 등 추가 요금 항목을 노란 블록으로 강조 표시. 항목이 없으면 미표시.
어드민 S03 객실 등록 · 추가 요금 설정 (label / 단가 / 단위)
h1_rooms[].extra_charges[]{label, amount_per_unit, unit}
정책 섹션 추가 요금 블록 (노란 배경)
10
엑스트라베드 요금
엑스트라베드 허용 객실에 한해 추가 요금과 제한 조건을 파란 블록으로 표시. 최대 인원(max_occupancy) 초과 불가 조건 명시.
어드민 S03 객실 등록 · 엑스트라베드 허용 / 요금 / 최대 수량
h1_rooms[].extra_bed_allowed · h1_rooms[].extra_bed_price · h1_rooms[].extra_bed_max
정책 섹션 엑스트라베드 요금 블록 (파란 배경, 허용 시만 표시)
엑스트라베드 추가 시에도 max_occupancy를 초과할 수 없음. 예약 시 검증 필요.
11
객실 시설 카테고리 헤더 (ROOM)
객실시설 섹션의 그룹 헤더. ROOM 도메인 카테고리명(plain string) 사용. PLACE 도메인 카테고리와 별개입니다.
어드민 S07-A/B 카테고리 관리 · 카테고리명 (ROOM 도메인, rmc##### 코드)
h1_facility_categories[].name (where domain = "ROOM")
객실시설 섹션 그룹 헤더 텍스트
12
객실 시설 항목명 (ROOM)
카테고리 그룹 내 시설명 칩. 객실에 적용된 ROOM 도메인 시설(facility_ids)만 카테고리별로 그룹화하여 표시.
S08-A 시설 목록 / S08-B 시설 등록 · 시설명 (ROOM) / S03 객실 등록 · 시설 선택
h1_rooms[].facility_ids → h1_facilities[].name (ROOM 도메인)
객실시설 섹션 카테고리 그룹 내 시설명 칩
