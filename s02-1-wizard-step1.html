취소 9 저장 8

화면 주석

1
5단계 마법사 탭바
화면 상단에 위치한 5개 단계 탭으로, 탭을 직접 클릭해 원하는 단계로 자유롭게 이동할 수 있다. 저장 버튼은 모든 단계에서 항상 노출되며, 저장 클릭 시 현재 단계 필드를 state에 동기화한 후 전 단계 필드를 합산 검증한다. 현재 단계(Step 1)는 짙은 배경으로, 완료된 단계는 초록 배경으로 구분된다.
임시저장 없음. 페이지 이탈 시 미저장 데이터 유실. 이탈 전 확인 다이얼로그 권장.
2
숙소코드 (자동 생성)
1차 분류(H=HOTEL / C=CONDO) + PMS BSDV_ID(시설구분코드) + SLST_ID(업장구분코드) 조합으로 자동 생성.
예: 메인타워 → H-01-1101, 팰리스 → H-02-1201, 마운틴콘도 → C-05-1601.
수정 화면에서는 이미 발급된 코드를 읽기 전용 필드로 표시하며 변경할 수 없다.
→ 프런트: 미노출 (내부 식별자)
3
1차 분류 (category)
HOTEL 또는 CONDO 중 하나를 선택한다. 선택 값에 따라 아래 2차 구역의 선택지가 자동으로 교체된다. 분류는 프런트 홈 화면의 Hotel·Condo 카드 구분 및 GNB 탭 라우팅에 직접 영향을 주는 핵심 속성이다. 저장 후 분류 변경 허용 여부는 실서비스에서 별도 정책 확정 필요.
→ 프런트: 홈 Hotel·Condo 카드 구분 / GNB Hotel·Condo 탭 라우팅 결정
4
2차 구역 (sub_place)
1차 분류가 HOTEL이면 grand_main / grand_convention / palace, CONDO이면 valley / hill / mountain 중 선택한다. 1차 분류 변경 시 선택지가 자동 교체되며, 이전에 선택한 값은 초기화된다. 선택된 값은 프런트 히어로 오버레이 서브명 라벨 및 상품 카드 상단의 서브 구역 칩에 직접 표시된다.
→ 프런트: 히어로 오버레이 서브명 라벨 / 상품 카드 상단 서브 구역 칩
5
숙소명 (place_name / place_name_en)
국문명은 필수 입력이며 영문명은 선택이다. 영문명을 입력하지 않으면 프런트 영문 모드에서 국문명이 대체 표시된다. 국문명은 숙소 선택 탭의 버튼 텍스트와 히어로 오버레이 대형 헤딩으로 사용된다. 공백 전후 트림 처리 권장.
→ 프런트: 숙소 선택 탭 버튼 텍스트 / 히어로 오버레이 대형 헤딩 텍스트
6
노출 여부 (visibility)
SHOW이면 프런트 브릿지 페이지 숙소 선택 탭과 히어로에 정상 노출된다. HIDE이면 해당 숙소가 탭 목록과 히어로에서 완전히 제거되어 고객이 볼 수 없다. 운영 중단이나 임시 비노출 상황에서 빠르게 숨김 처리할 수 있는 수단으로 활용된다. HIDE 상태에서도 어드민에서 숙소 데이터는 유지되므로 필요 시 SHOW로 즉시 복구 가능하다.
→ 프런트: HIDE이면 브릿지 페이지 숙소 탭 목록에서 제거
7
체크인·체크아웃 시각
TIME_CD = B타입으로 고정 운영. 관리자 입력 불가, 수정 불가.
PMS API 5 BLKTIME_TYPE_CLS_NM 값을 자동으로 표시. 현재 값: "B타입: 15:00 ~ 11:00".
프런트 브릿지 페이지 Overview 섹션에 체크인/체크아웃 시각으로 직접 노출된다.
→ 프런트: 브릿지 페이지 Overview 섹션 체크인/체크아웃 시각 값
8
[저장] 버튼 — 전체 저장 (Step 1~5)
현재 단계(Step N)만 저장하는 것이 아님. 어느 단계에서 [저장]을 눌러도 Step 1~5 전 단계 데이터를 합산하여 검증 후 숙소 1개(h1_places[]) 전체를 localStorage에 저장.

동작 순서: 현재 단계 필드를 state에 동기화 → 1~5단계 전 필드 필수값·형식 검증 → 통과 시 localStorage 즉시 기록 → 숙소 목록으로 이동.
S06 상품 등록(탭별 저장)과 다름. S02는 단일 숙소 엔티티를 5단계에 걸쳐 입력하므로 전체 저장 방식 적용.
저장 실패 시 어느 단계·어느 필드에 문제가 있는지 명확히 안내 필요.
9
[취소] 버튼
미저장 변경사항을 모두 파기하고 숙소 목록(#/places)으로 이동. 신규 등록 중이면 작성한 모든 내용이 사라짐.
이탈 전 "저장하지 않은 내용이 있습니다. 나가시겠습니까?" 확인 다이얼로그 표시 권장.
10
숙소 소개 (description)
숙소를 소개하는 한 줄~단락 문구. 선택 입력. 비어있으면 프런트 Overview에서 해당 영역 미표시.
→ 프런트: 브릿지 페이지 Overview 섹션 숙소 소개 문구 영역
11
변경이력 (A안 — 접이식 섹션)
수정 화면 하단에 위치한 접이식(아코디언) 섹션. 기본 상태는 펼쳐짐. 헤더 클릭 시 접기/펼치기 토글.
이력 기록 조건: [저장] 성공 시 아래 항목 중 변경이 있는 경우에만 새 이력 행 생성.
기록 대상 항목: 숙소명(국문), 노출여부. (체크인·체크아웃 시각은 PMS API 5 고정값, 이력 기록 제외.)
이력 컬럼: 변경일시 / 변경자 / 항목 / 변경 전 / 변경 후 / 사유(선택입력).
신규 등록 시 이력 없음 ("이력이 없습니다" 문구 표시). 최신 이력이 상단.
