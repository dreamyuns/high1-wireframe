화면 주석

1
편집 중인 상품 컨텍스트
달력 편집 중에도 어떤 상품을 편집 중인지 상단 컨텍스트 바에 표시. S06-A ↔ S06-B ↔ S06-C 간 이동 시 상품 정보 유지.
2
탭2 — 재고·요금 (인벤토리)
목록형(S06-B)과 달력형(S06-C)은 동일한 inventory[] 배열을 편집하는 2가지 뷰. 둘 중 어디서 저장해도 같은 데이터에 반영됨.
3
달력형 뷰
월 단위 캘린더로 전체 재고·요금 현황을 한눈에 파악. 주말 요금 차등, 성수기 구간 등 날짜별 상태를 시각적으로 확인할 때 유용.
목록형(S06-B)에서도 동일 inventory[] 편집 가능. 구간 일괄 적용은 S06-B에서 사용.
4
월 이동
◀/▶ 버튼으로 이전/다음 달 전환. 현재 월이 중앙에 표시됨.
5
미설정 날짜
inventory[]에 해당 날짜 데이터가 없는 상태. 프런트에서 'no_inv' 처리 → 해당일 숙박 불가.
→ 프런트: 미설정 날짜가 숙박 범위에 포함되면 상품 카드 '재고 없음' 상태
6
색상 코딩
초록(재고 있음) / 빨강(SOLD OUT, stock=0) / 회색(체크인불가, check_in_allowed=N) / 흰색(미설정) / 파랑(선택된 셀).
7
편집 패널 (셀 클릭 시 활성화)
달력 셀 클릭 시 우측 패널에서 해당 날짜의 입금가·재고·체크인허용·최소박·최대박·컷오프를 개별 편집. 판매가는 입금가 기준 마진 적용 후 자동 계산(읽기 전용).
구간 일괄 적용(S06-B) 후 개별 날짜 미세 조정 시 주로 사용.
8
입금가 (price)
해당 날짜 1박 원가. PMS연동 상품은 [요금 동기화] 버튼 클릭 시 API 3(SELL_ITM_AMT) 동기화 금액, 수기 상품은 관리자 직접 입력. 달력 셀에 "입 XXX,XXX"로 표시.
→ 프런트: 미노출. 고객에게는 판매가(⑰)만 표시.
17
판매가 (sell price) — 읽기 전용
입금가에 마진(S11/S06-A)을 적용한 고객 청구 금액. 자동 계산, 직접 수정 불가. 달력 셀에 "판 XXX,XXX"로 표시.
계산식: 입금가 × (1 + 마진율) 또는 입금가 + 마진금액. 소수점 버림(floor).
→ 프런트: 상품 카드 총 금액(판매가 기준). API 6 SELL_AMT는 입금가로 전송 (판매가 아님).
9
사용가능 객실수 (읽기전용)
달력 셀 및 편집 패널 모두 읽기전용. 이 화면에서 수정 불가.
PMS연동 상품: API 4 RSV_CNT. 수기 상품: 총 재고 − 예약 수.
재고 변경은 객실 상세 > 재고관리 탭에서 수행. 0이면 SOLD OUT 표시.
→ 프런트: stock ≤ 0 → 'SOLD OUT' 상태
10
컷오프 (cutoff_days_before_checkin)
체크인 N일 전 예약 차단. N=0이면 당일까지 예약 가능.
→ 프런트: today ≥ (체크인 − N일) 이면 '예약 마감' 상태
11
저장 범위 — 탭2(인벤토리)만
S06-C의 [저장]은 탭2 인벤토리(inventory[])만 localStorage에 기록. 탭1(S06-A) 마스터·취소정책 데이터는 건드리지 않음.
S06-A [저장] ↔ S06-B/C [저장]은 각자 독립적으로 동작하며, 서로의 데이터를 덮어쓰지 않음.
PR-FORM-04: 저장 전 날짜 중복 자동 검증. 중복 있으면 저장 차단 후 중복 날짜 목록 표시.
12
패널 [저장] / [취소] 버튼
[저장]: 선택된 날짜의 변경사항을 페이지 state(메모리)에 반영. 달력 셀 색상·숫자가 즉시 갱신됨. localStorage에는 아직 기록하지 않음.
[취소]: 변경 파기. 패널 입력값을 편집 전 원래 값으로 복원. 패널은 열린 상태 유지.
패널 [저장] ≠ localStorage 저장. 최종 기록은 하단 ⑭ [저장] 버튼에서 수행.
13
[이 날짜 삭제] 버튼
선택된 날짜를 페이지 state에서 제거. 달력 셀이 즉시 "미설정"(흰색)으로 변경됨. localStorage에는 반영되지 않음.
확인 다이얼로그 없이 즉시 제거. 하단 ⑮ [취소]로 전체 복구 가능.
14
하단 [저장] 버튼
탭2 인벤토리(inventory[]) 데이터를 localStorage에 최종 기록. 패널 [저장](⑫)으로 state에 반영해 둔 모든 변경사항이 이 시점에 확정됨.
저장 전 날짜 중복 자동 검증(⑪). 중복 있으면 저장 차단.
15
하단 [취소] 버튼
페이지의 모든 변경사항(날짜 편집·삭제 포함)을 파기하고 상품 목록(S05)으로 이동. localStorage에 저장되지 않은 변경만 파기됨.
이 버튼으로 패널 [저장](⑫)·[이 날짜 삭제](⑬)로 state에 반영한 변경도 모두 복구 가능.
16
요금 동기화 (PMS연동 모드 전용)
[PMS연동 모드]: 상품 등록 후 최초 1회 [요금 동기화] 버튼 클릭 필수 → API 3(otaHbItmInfo.do) 호출하여 달력에 날짜별 입금가(SELL_ITM_AMT) 초기 적재. 이후 배치 자동 업데이트. 배치 실패 시 버튼으로 fallback. 달력 셀 요금은 읽기 전용(편집 패널 비활성).
재고(AVLB_RM_CNT)는 S04-INV에서 별도 관리(API 4). 이 화면에서는 읽기전용으로만 표시.
[수기 모드]: 이 배너 숨김. 기존 달력 편집 UI(⑦~⑮) 그대로 표시.
[요금 동기화] 버튼 클릭 시: "PMS 요금 값으로 입금가가 덮어쓰기 됩니다. 진행하시겠습니까?" 확인 팝업 표시. 취소 시 동기화 중단.
PMS연동 모드에서는 편집 패널 입력, [이 날짜 삭제] 버튼 모두 비활성화.
18
이력 보기 (B안 — 날짜 필터 모달)
달력 상단 오른쪽 [이력 보기] 버튼 클릭 시 변경이력 조회 모달 표시.
조회기간(시작일~종료일) 설정 후 [조회] 클릭 → 해당 기간 내 날짜별 인벤토리 변경 이력만 필터링 표시.
이력 기록 조건: 날짜별 입금가·재고 변경 시 자동 기록 (패널 저장 → 하단 저장 완료 시점 기준).
이력 컬럼: 변경일시 / 변경자 / 적용날짜 / 변경구분(수동·PMS동기화) / 항목 / 변경 전 / 변경 후.
수동 변경과 PMS동기화는 배지로 구분. PMS동기화 이력은 별도 동기화 로그 테이블에서 조회.
S06-B와 동일한 이력 데이터. 뷰만 다름.
