화면 주석

1
편집 중인 상품 컨텍스트
달력 편집 중에도 어떤 상품을 편집 중인지 상단 컨텍스트 바에 표시. S06-A ↔ S06-B ↔ S06-C 간 이동 시 상품 정보 유지.
2
탭2 — 재고·요금 (인벤토리)
목록형(S06-B)과 달력형(S06-C)은 동일한 inventory[] 배열을 편집하는 2가지 뷰. 둘 중 어디서 저장해도 같은 데이터에 반영됨.
3
달력형 뷰
월 단위 캘린더로 전체 재고·요금 현황을 한눈에 파악. 주말 요금 차등, 성수기 구간 등 날짜별 상태를 시각적으로 확인할 때 유용.
목록형(S06-B)에서도 동일 inventory[] 편집 가능. 구간 일괄 적용은 S06-B에서 사용.
4
월 이동
◀/▶ 버튼으로 이전/다음 달 전환. 현재 월이 중앙에 표시됨.
5
미설정 날짜
inventory[]에 해당 날짜 데이터가 없는 상태. 프런트에서 'no_inv' 처리 → 해당일 숙박 불가.
→ 프런트: 미설정 날짜가 숙박 범위에 포함되면 상품 카드 '재고 없음' 상태
6
색상 코딩
초록(재고 있음) / 빨강(SOLD OUT, stock=0) / 회색(체크인불가, check_in_allowed=N) / 흰색(미설정) / 파랑(선택된 셀).
7
날짜 상세 패널 (읽기전용)
달력 셀 클릭 시 우측 패널에 해당 날짜의 입금가·판매가·재고·판매 ON/OFF·최소박·최대박·컷오프를 읽기전용으로 표시만 한다. 입력·저장·삭제 없음. (판매 ON/OFF·재고·요금은 S04-INV 관리)
예약조건 변경은 목록형(S06-B) 구간 일괄(벌크) 적용에서 수행. 달력형은 현황 조회 전용.
8
입금가 (price) — 읽기전용
해당 날짜 1박 원가. 이 화면에서 수정 불가(읽기전용). PMS(API 3, SELL_ITM_AMT) 연동으로 수신하며 요금 갱신은 S04-INV(객실 타입)에서 수행. 달력 셀에 "입 XXX,XXX"로 표시.
→ 프런트: 미노출. 고객에게는 판매가(⑰)만 표시.
17
판매가 (sell price) — 읽기 전용
입금가에 마진(S11/S06-A)을 적용한 고객 청구 금액. 자동 계산, 직접 수정 불가. 달력 셀에 "판 XXX,XXX"로 표시.
계산식: 입금가 × (1 + 마진율) 또는 입금가 + 마진금액. 소수점 버림(floor).
→ 프런트: 상품 카드 총 금액(판매가 기준). API 6 SELL_AMT는 입금가로 전송 (판매가 아님).
9
사용가능 객실수 (읽기전용)
달력 셀 및 편집 패널 모두 읽기전용. 이 화면에서 수정 불가.
PMS연동 상품: API 4 RSV_CNT. 수기 상품: 총 재고 − 예약 수.
재고 변경은 객실 상세 > 재고관리 탭에서 수행. 0이면 SOLD OUT 표시.
→ 프런트: stock ≤ 0 → 'SOLD OUT' 상태
10
컷오프 (cutoff_days_before_checkin)
체크인 N일 전 예약 차단. N=0이면 당일까지 예약 가능.
→ 프런트: today ≥ (체크인 − N일) 이면 '예약 마감' 상태
12
조회 전용 패널 안내
달력형 상세 패널은 조회 전용이다. 패널 [저장]·[취소]·[이 날짜 삭제] 버튼은 모두 제거되었다.
예약조건(최소/최대박·컷오프) 변경은 목록형(S06-B) 구간 일괄(벌크) 적용에서만 수행한다. 판매 ON/OFF·재고·요금은 S04-INV 관리.
14
하단 안내 — 저장 없음
달력형은 조회 전용이라 [저장] 버튼이 없다. 재고·요금은 읽기전용(PMS/S04-INV), 예약조건 저장은 목록형(S06-B)에서 수행.
15
[목록으로] 버튼
상품 목록(S05)으로 이동. 달력형은 조회 전용이므로 파기할 변경사항이 없다.
16
재고·요금·날짜 읽기전용 안내
날짜·입금가·판매가·재고는 이 화면에서 수정·삭제 불가(읽기전용).
요금(입금가)은 S04-INV(객실 타입)에서 PMS(API 3, SELL_ITM_AMT) 동기화로 갱신 → 달력은 그 값을 참조해 표시만. 재고(API 4 AVLB_RM_CNT)도 S04-INV/PMS 연동. 날짜(인벤토리)는 PMS 연동으로만 생성.
[요금 동기화] 버튼은 S06에서 제거 — 요금 갱신 창구는 S04-INV로 일원화.
전 상품 PMS 연동 운영 전제. 달력형은 예약조건 편집도 하지 않는 순수 조회 뷰(예약조건 변경은 S06-B 벌크).
18
이력 보기 (B안 — 날짜 필터 모달)
달력 상단 오른쪽 [이력 보기] 버튼 클릭 시 변경이력 조회 모달 표시.
조회기간(시작일~종료일) 설정 후 [조회] 클릭 → 해당 기간 내 날짜별 인벤토리 변경 이력만 필터링 표시.
이력 기록 조건: 날짜별 입금가·재고 변경 시 자동 기록 (패널 저장 → 하단 저장 완료 시점 기준).
이력 컬럼: 변경일시 / 변경자 / 적용날짜 / 변경구분(수동·PMS동기화) / 항목 / 변경 전 / 변경 후.
수동 변경과 PMS동기화는 배지로 구분. PMS동기화 이력은 별도 동기화 로그 테이블에서 조회.
S06-B와 동일한 이력 데이터. 뷰만 다름.
