데이터 연결 매핑표 참고

어드민에서 입력한 각 필드가 어떤 localStorage 키에 저장되고, 프런트 화면 어디에 어떻게 노출되는지를 한눈에 정리한 참고표입니다.

아키텍처 요약
어드민(admin-prototype-v0.4/)은 localStorage에 쓰기만 수행합니다. 프런트(front-prototype_v0.4/)는 동일한 키를 읽기 전용으로 사용합니다. 두 프로토타입은 같은 브라우저 도메인에서 실행되어야 localStorage를 공유합니다.

다국어 정책
숙소·객실·상품의 텍스트 필드는 { ko, en } 객체로 저장됩니다. 공통 마스터(카테고리·시설·객실유형)의 이름은 plain string(한국어 단일값)으로 저장됩니다.
