화면 주석

1
히어로 이미지 영역 — 개요
프런트 메인 최상단 슬라이드쇼 영역. 이미지·동영상 혼용 가능, 최대 10장.
히어로 영역과 추천 섹션 영역은 독립적으로 저장되며 서로 영향을 주지 않는다.
→ 프런트: 메인 최상단 전체 폭 슬라이드쇼 영역
2
전역 설정 — 자동 슬라이드
자동 슬라이드 ON: 설정한 주기(초 단위, 최소 1초)마다 다음 슬라이드로 자동 전환.
자동 슬라이드 OFF: 고객이 좌우 화살표·점 네비게이터로 수동 전환.
기본값: ON / 5초.
전역 설정은 전체 슬라이드에 일괄 적용. 슬라이드별 개별 주기 없음.
3
슬라이드 목록 — 순서·상태
노출 순서는 순서(order) 필드 값 기준으로 정렬해 표시. ≡ 핸들 드래그로 끌어 놓아 재정렬하는 기능은 향후 적용 예정.
미디어 유형: 이미지(파란 배지) / 동영상(보라 배지).
상태 ON: 노출 기간 내 + 강제종료 미적용.
상태 OFF: 노출 기간 경과 또는 강제종료 적용.
강제OFF 배지: 강제종료 적용 시 강제종료 컬럼에 빨간 배지 표시.
노출 기간이 지난 슬라이드는 자동 OFF 처리. 목록에는 잔류(이력 보존).
[삭제] 버튼 클릭 시 confirm 알럿 → 확인 후 삭제 처리.
4
[+ 슬라이드 추가] 버튼
S12-B 히어로 슬라이드 등록 폼으로 이동.
등록된 슬라이드가 10장에 달하면 버튼 비활성화(disabled).
비활성 상태에서 호버 시 "최대 10장 등록 완료" 툴팁 표시.
5
[저장] 버튼 — 전역 설정 전용
전역 설정(자동 슬라이드 ON/OFF, 주기)만 저장하는 버튼.
슬라이드 노출 순서는 순서(order) 필드 값으로 정렬(드래그 재정렬은 향후).
개별 슬라이드 내용(이미지, 텍스트, CTA 등)은 S12-B에서 각각 저장.
6
추천 섹션 영역 — 개요
프런트 메인의 추천 섹션 목록을 관리. 섹션 추가·삭제·순서 조정 가능.
섹션은 유형(숙소/티켓)으로 나뉜다. 숙소 섹션과 티켓 섹션은 각각 다른 폼으로 등록하며, 목록에서 유형 배지로 구분한다. (투어는 추후)
→ 프런트: 히어로 아래 섹션 순서대로 노출. 숙소 섹션=객실 카드 그리드 / 티켓 섹션=티켓 카드 가로 스트립(클릭 시 카테고리 브릿지).
추천 대상(객실/티켓) 0건 섹션은 프런트에서 섹션 전체 자동 미노출.
7
섹션 목록 — 행 구성·순서
섹션 노출 순서는 순서(order) 필드 값 기준으로 정렬해 표시. ≡ 핸들 드래그 재정렬은 향후 적용 예정.
숙소 필터: 선택한 2뎁스 숙소명 요약. 미선택 시 "전체".
객실 선택: "자동 · 정렬기준" 또는 "수동 · N개" 형식으로 요약 표시.
[삭제] 버튼 클릭 시 confirm 알럿 → 확인 후 삭제 처리.
8
[+ 숙소 섹션 추가] 버튼
S12-C 추천 섹션 설정(숙소) 폼으로 이동. 카테고리(Hotel/Condo)→숙소→객실 자동/수동. 섹션 수 상한 없음.
9
유형 배지 (숙소 / 티켓)
각 섹션이 숙소 섹션인지 티켓 섹션인지 표시. 숙소(파랑) / 티켓(로즈).
유형에 따라 컬럼 의미가 다름 — 숙소: 카테고리=Hotel/Condo·숙소 필터 사용 / 티켓: 카테고리=티켓 카테고리(워터파크 등)·숙소 필터 없음(—). "선택" 컬럼은 공통(자동 정렬 / 수동 N개).
10
[+ 티켓 섹션 추가] 버튼
S12-D 티켓 추천 섹션 설정 폼으로 이동(숙소 섹션과 분리). 티켓 전용: 타이틀·노출기간·전체보기 버튼 + 선택방식 자동(카테고리 필터+정렬[최저가순/이름순])/수동(티켓 상품 직접 선택). 카드=썸네일·상품명·최저가.
티켓 카드 클릭 시 해당 카테고리 브릿지로 이동.
