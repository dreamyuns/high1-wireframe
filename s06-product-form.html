2
객실 선택 UI (2패널) / PMS 불러오기 케이스
UI 구조: 좌측 패널(숙소 목록) 클릭 → 우측 패널(해당 숙소 객실 목록) 갱신. 라디오 버튼으로 단일 선택. room_id 저장.
패널에는 등록된 객실만 표시. 수기 포함 반드시 객실 등록 → 상품 등록 순서.

[PMS연동 모드 — PMS 불러오기 케이스]: API 3 호출 → RM_TYP_CD 기준 자동 처리.
① 동일 RM_TYP_CD 매핑 객실 존재 → 기존 객실 자동 연결 + 확인 알럿 표시.
② 해당 RM_TYP_CD 매핑 객실 없음 → 케이스② 처리:
  • 알럿 노출: "현재 등록된 객실이 없습니다. 객실 등록 후 다시 상품을 등록해 주세요."
  • 알럿 [확인] → 상품 폼 유지 (기입력값 보존) + 경고 박스 자동 표시
  • 저장 버튼 비활성 처리 (상품 저장 불가)
  • 경고 박스 내 [↗ S04 객실 등록 (새 탭)] 버튼 클릭 → S04 새 탭 오픈
  • S04에서 객실 등록 완료 후 이 폼으로 복귀 → [PMS 불러오기] 재시도 → 케이스① 처리
③ RM_TYP_CD = null: API 3 응답에서 RM_TYP_CD는 항상 값 있음 (null 불가, ITM_ID 구조에 포함). 발생하지 않음.
→ 프런트: 선택된 객실의 이미지·침대·인원 등이 상품 카드·모달에 함께 표시됨.
같은 RM_TYP_CD에 N개 상품 연결 가능. 임시저장 기능은 추후 추가 예정. 검색 기능은 추후 추가 예정 (현재 미포함).

8
취소 정책 (연동 모드별 분기)
[수기 모드]: 동적 구간 입력 UI. [+ 구간 추가]로 행 추가, 각 행에서 기준일(셀렉트) + 위약금율(%) 입력. 노쇼(당일 24시 이후) 행은 100% 고정으로 삭제 불가. 동일 기준일 중복 방지. 위약금액 = 판매가 × 위약금율.
기준일 선택지: 8일 이상 전 / 7일 전 / 6일 전 / 5일 전 / 4일 전 / 3일 전 / 2일 전 / 1일 전 / 당일 24시 이전
[PMS연동 모드]: API 9(otaHbDfltRgltInfo.do) 데이터를 동일 구조로 읽기 전용 표시. 관리자 직접 수정 불가.
→ 프런트: 상품 카드 취소 정책 요약 텍스트 (무료 취소 가능일 표시)
부분취소 정의: 위약금 있는 전체 취소. API 10(위약금 확인) → 관리자 확인 → API 7(취소) 흐름.
9
연동 모드 · PMS 상품 불러오기
연동 모드: PMS연동 / 수기관리 중 선택. 상품 등록 시 최초 1회 결정, 이후 변경 불가. 전환 필요 시 현재 상품 OFF 후 신규 생성.
PMS연동 선택 시: 숙소(SLST_ID) 선택 → 상품 목록 로드 → 상품 선택 (포맷: RM_TYP_CD(RM_TYP_NM) / ITM_ID(ITM_NM)) → [PMS 연동하기] 클릭. API 3 호출하여 상품명·인원·최소박수·PKG_YN 등을 폼에 자동 채움. ITM_ID는 product.pms_itm_id로 저장.
수기 모드 선택 시 PMS 상품 선택 UI는 숨김 처리. ITM_ID는 null.
10
노출 여부 (객실 Cascade 연동)
SHOW(Y) / HIDE(N) select는 항상 표시 (disabled 없음). cascade 상태 시 select 아래에 색상 경고 박스 추가.
정상(객실 등록 + SHOW): select만 표시. 관리자 직접 SHOW/HIDE 선택.
객실 HIDE: 회색 경고 박스 "🔒 객실 HIDE — 강제 미노출(N)". S04에서 객실 SHOW 전환 시 자동 해제.
노출 조건: 객실SHOW AND 상품SHOW (2단). 상세: policy-decisions.html 섹션 12.
11
마진 설정 (2단계 계층)
OFF(기본, 마스터 상속): 공통관리 > 시설 마진 마스터(S11) 값을 자동 상속. 마스터 변경 시 즉시 반영.
ON(개별 설정): 마진율(%) 또는 마진금액(원) 선택 후 입력. 마스터 오버라이드. 마진율 범위 -49%~+100%(정수), 마진금액 하한 없음.
판매가 = 입금가 × (1 + 마진율/100) 또는 입금가 + 마진금액. 소수점 버림(floor).
SELL_AMT(API 6) = 입금가(PMS 원가)로 전송. 마진 미포함. (판매가는 우리 DB에만 저장)
→ 프런트: 상품 카드 노출 가격 = 판매가
이력 관리 필수: 변경일시·변경자·변경 전/후 값. S11 상세 정책: s11-margin-policy.html 참조.
12
탭3 — 변경이력 (C안)
탭1·탭2와 동일한 탭바에 위치한 세 번째 탭. 상품 마스터 필드의 변경 내역을 시계열 테이블로 표시.
이력 기록 조건: 탭1 [저장] 성공 시 아래 항목 중 변경이 있는 경우에만 새 이력 행 생성.
기록 대상 항목: 상품명, 판매기간(시작·종료), 마진(마진율 또는 마진금액), 취소정책(수기 모드 구간 변경), 노출여부.
이력 컬럼: 변경일시 / 변경자 / 항목 / 변경 전 / 변경 후 / 사유(선택입력).
PMS연동 모드 취소정책은 API 읽기 전용이므로 이력 미기록. 최신 이력이 상단.
