2. 마진 계산 규칙

입력 방식 — 마진율(%) 또는 마진금액(정액) 중 하나 선택

마진율 적용: 실판매가 = floor( 기준가 × (1 + 마진율 ÷ 100) )
마진금액 적용: 실판매가 = 기준가 + 마진금액
항목 마진율 (%) 마진금액 (정액)
입력 형식 정수만 (소수점 입력 불가) 정수 원(₩) 단위
허용 범위 -49% ~ +100% 음수 허용 (하한 TBD — 아래 참조)
음수 의미 할인 (기준가 대비 % 인하) 할인 (정액 차감)
양수 의미 마크업 (기준가 대비 % 인상) 마크업 (정액 가산)
소수점 처리 계산 결과 소수점 발생 시 무조건 버림(floor) → 정수로 노출
계산 예시 (마진율) 기준가 100,000원 / 마진율 +10% → 실판매가 110,000원
기준가 100,000원 / 마진율 -20% → 실판매가 80,000원
기준가 33,333원 / 마진율 +10% → 33,333 × 1.1 = 36,666.3 → 실판매가 36,666원 (소수점 버림)
TBD-1 · 마진금액 하한선 마진금액이 음수이고 절댓값이 기준가를 초과하면 실판매가가 0 이하가 됩니다. 실판매가 최솟값(예: 1,000원)을 설정할지 결정 필요합니다.
3. 2단계 마진 계층 구조
단계설정 위치적용 범위변경 즉시 반영
1단계 시설 마진 마스터 S11-A/B 마진관리 해당 시설의 개별 마진 미설정 상품 전체 ✅ 즉시
2단계 상품 개별 마진 S06-A 마진 섹션 해당 상품만 ✅ 즉시
적용 우선순위 상품 개별 마진 설정 시 → 상품 개별 마진 사용 (마스터 무시)
상품 개별 마진 미설정 시 → 시설 마진 마스터 자동 상속
시설 마진 마스터도 없을 경우 → 마진 0 (기준가 = 실판매가)
이력 관리 필수 아래 두 가지 이력을 반드시 기록합니다.
  • 시설 마진 마스터 변경 이력: 변경일시 · 변경자 · 변경 전/후 값
  • 상품 개별 마진 설정 이력: 개별 설정 ON/OFF 전환 시점 · 변경 전/후 값
"개별 마진 해제 → 마스터 복귀" 시점도 이력에 포함해야 실판매가 변동 원인을 추적 가능합니다.

화면 주석

1
마진율 소수점 불가
마진율 입력 필드는 정수만 허용합니다. 소수점 키 입력 자체를 차단합니다 (입력 이벤트 레벨에서 처리).
UI-MAR-01: 마진율 입력 필드 type="number" step="1" min="-49" max="100"
2
소수점 버림(floor) 처리
실판매가 계산 시 Math.floor() 적용. 반올림(round) 아님에 주의합니다. 33,333 × 1.1 = 36,666.3 → 36,666원 (버림)
BIZ-MAR-01: 실판매가 = Math.floor(기준가 × (1 + 마진율/100))
3
PMS 연동 상품 미리보기
PMS 연동 상품은 날짜별로 기준가가 다르므로, S06-A 마진 섹션의 실판매가 미리보기는 예시 금액으로 표시합니다. 실제 날짜별 실판매가는 S06-B/C 인벤토리 화면에서 확인합니다.
4
개별 마진 해제 시
상품에서 개별 마진을 해제하면 시설 마스터로 즉시 복귀됩니다. 이 전환 시점을 이력으로 기록해야 실판매가 변동 원인 추적이 가능합니다.
BIZ-MAR-02: 마진 설정 변경 시 변경일시·변경자·변경 전/후 값 필수 기록
5
LNB 위치 — 공통관리
마진관리는 숙소·티켓·투어에 걸친 공통 기능이므로 공통관리 LNB 하위에 위치합니다.
LNB 공통관리: 카테고리관리 / 시설관리 / 객실유형관리 / 마진관리
6
마진 0 처리
시설 마진 마스터가 설정되지 않은 경우 마진 0으로 처리합니다. 이 경우 기준가 = 실판매가가 됩니다. 마진 미설정 시 경고 표시는 불필요합니다.
