S11 마진관리 정책 — #/margin-management · 공통관리 하위 메뉴
✅ 확정 반영본 (프로토타입 v0.6 기준) — 마진관리 화면(S11 단일 인라인 편집)과 일자별 마진(S06-B) 정책을 정의합니다. 마진 마스터는 공통관리 하위 · 객실 타입(RM_TYP_CD)별이며, 실제 화면은 S11 마진관리 · S06-B 재고·요금 참조.
1. 용어 정의
용어정의출처
입금가 마진 적용 전 원가. 고객에게 노출하지 않음. PMS 연동: SELL_ITM_AMT (API 3 — 요금의 유일한 소스)
수기 관리: 어드민 직접 입력가
판매가 입금가에 마진을 적용한 후 고객에게 청구되는 금액.
프런트 노출가 기준.		 입금가 + 마진 계산 결과 (소수점 버림)
마진 마스터 공통관리에서 객실 타입(RM_TYP_CD) 단위로 설정하는 기본 마진(디폴트).
일자별 마진을 개별 설정하지 않은 날짜에 자동 상속.		 S11 마진관리 화면에서 관리
일자별 마진 날짜(재고·요금 행)별 독립 마진.
개별 설정 시 마스터를 오버라이드(개별), 미설정 시 마스터 상속(상속).		 S06-B 재고·요금 탭에서 관리
전역 디폴트 마진 마스터에도 값이 없을 때 적용하는 최종 기본값. 마진금액 30,000원 (DEFAULT_DAILY_MARGIN)
2. 마진 계산 규칙

입력 방식 — 마진율(%) 또는 마진금액(정액) 중 하나 선택

마진율 적용: 판매가 = floor( 입금가 × (1 + 마진율 ÷ 100) )
마진금액 적용: 판매가 = 입금가 + floor(마진금액)
항목 마진율 (%) 마진금액 (정액)
입력 형식 정수만 (소수점 입력 불가) 정수 원(₩) 단위
허용 범위 -49% ~ +100% 음수 허용 · 하한 없음(제한하지 않음, 확정)
음수 의미 할인 (입금가 대비 % 인하) 할인 (정액 차감)
양수 의미 마크업 (입금가 대비 % 인상) 마크업 (정액 가산)
소수점 처리 계산 결과 소수점 발생 시 무조건 버림(floor) → 정수로 노출. 판매가 최소 0.
계산 예시 (마진율) 입금가 100,000원 / 마진율 +10% → 판매가 110,000원
입금가 100,000원 / 마진율 -20% → 판매가 80,000원
입금가 33,333원 / 마진율 +10% → 33,333 × 1.1 = 36,666.3 → 판매가 36,666원 (소수점 버림)
3. 2단계 마진 계층 구조
단계설정 위치단위적용 범위
1단계 마진 마스터 S11 마진관리 (공통관리) 객실 타입(RM_TYP_CD) 해당 타입의 일자별 마진 디폴트로 주입
2단계 일자별 마진 S06-B 재고·요금 (상품) 날짜(행) 해당 날짜만 (개별/상속)
적용 우선순위 일자별 마진을 개별 설정 → 그 값 사용 (마스터 무시)
일자별 마진 상속(유형 '없음') → 마진 마스터(RM_TYP_CD) 값 상속
마진 마스터도 없을 경우 → 전역 디폴트(마진금액 30,000원)
이력 관리 필수 아래 이력을 반드시 기록합니다.
  • 마진 마스터 변경 이력: 변경일시 · 변경자 · 변경 전/후 값 (RM_TYP_CD 단위)
  • 일자별 마진 변경 이력: 개별 설정/해제(상속 복귀) 시점 · 변경 전/후 값
"개별 마진 해제 → 마스터 상속 복귀" 시점도 이력에 포함해야 판매가 변동 원인을 추적 가능합니다.

5. S11 마진관리 화면 기능 정의

테이블 컬럼 (행 = 객실 타입 RM_TYP_CD)

컬럼내용

6. S06-B 일자별 마진 UI
재고·요금 목록형 · 마진 컬럼 (행별 편집)
유형 없음(상속) 마진금액 마진율% 개별
판매가 자동 계산: 입금가 340,000 + 마진금액 34,000 → 374,000원 ('없음' 선택 시 마스터(S11) 상속 → 미설정이면 전역 30,000원)
7. SELL_AMT 처리 (API 6)
확정 PMS 예약 요청(API 6) 시 SELL_AMT = 입금가 (PMS 원가, 마진 미포함).
마진은 우리 쪽 수취분이며, PMS에는 원가만 전달합니다.
환불·위약금 계산 환불 예정액 = 우리 DB 판매가 − API 10 DLFT_APLY_AMT
위약금율 = DLFT_APLY_AMT ÷ SELL_AMT(입금가) · 고객 청구 위약금 = 위약금율 × 판매가 (소수점 첫째자리 반올림)
PMS 납부 = DLFT_APLY_AMT 원금 그대로 · 차액(마진 비례분)은 우리 수취. ※ API 10 실제 필드명 오타: DLFT_APLY_AMT (DFLT 아님)

9. 확인 필요 (대화창 1 · 사업부 정책서 동기화)
FLAG-1 · 마진 계층 단위 본 문서·프로토타입은 마진 마스터를 객실 타입(RM_TYP_CD) 단위 + 일자별(S06-B)로 정의합니다. CLAUDE.md 마진 계층 기술은 "시설(Place) 단위 마스터 + S06-A 상품 개별"로 되어 있어 단위·위치가 상이합니다. context/사업부-정책서.md 동기화가 필요합니다.

화면 주석

1
마진율 소수점 불가
마진율 입력 필드는 정수만 허용합니다. 소수점 키 입력 자체를 차단합니다 (입력 이벤트 레벨에서 처리).
UI-MAR-01: 마진율 입력 필드 type="number" step="1" min="-49" max="100"
2
소수점 버림(floor) 처리
판매가 계산 시 Math.floor() 적용. 반올림(round) 아님에 주의합니다. 33,333 × 1.1 = 36,666.3 → 36,666원 (버림)
BIZ-MAR-01: 판매가 = Math.floor(입금가 × (1 + 마진율/100)) 또는 입금가 + Math.floor(마진금액)
3
일자별 판매가 (PMS 연동)
PMS 연동 상품은 날짜별로 입금가가 다르므로, 판매가도 날짜별로 계산됩니다. S06-B 재고·요금 탭에서 각 날짜 행의 판매가를 실시간으로 확인합니다.
4
개별 마진 해제 시 (상속 복귀)
일자별 마진 유형을 '없음'으로 바꾸면 마진 마스터(RM_TYP_CD)로 즉시 상속 복귀됩니다. 이 전환 시점을 이력으로 기록해야 판매가 변동 원인 추적이 가능합니다.
BIZ-MAR-02: 마진 설정 변경 시 변경일시·변경자·변경 전/후 값 필수 기록
5
LNB 위치 — 공통관리
마진관리는 숙소·티켓·투어에 걸친 공통 기능이므로 공통관리 하위에 위치합니다.
LNB 공통관리: 카테고리관리 / 시설관리 / 객실유형관리 / 마진관리
6
전역 디폴트 (마진 0 아님)
마진 마스터가 설정되지 않아도 마진 0이 아니라 전역 디폴트(마진금액 30,000원)가 적용됩니다. 즉 어떤 날짜든 최소한 전역 디폴트 마진이 얹혀 판매가가 계산됩니다.
DEFAULT_DAILY_MARGIN = { type:"amount", value:30000 }
