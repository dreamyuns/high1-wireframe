화면 주석

1 도메인 탭 (PLACE / ROOM)
숙소 시설 카테고리와 객실 시설 카테고리를 별도 탭으로 분리 관리. 코드 체계가 다름: PLACE → plc##### / ROOM → rmc#####. 경로도 별도: #/categories/place, #/categories/room.
CM-CAT-01: 도메인별 코드 체계 분리 필수.
2 카테고리 코드
PLACE 도메인: plc00001부터 순번. ROOM 도메인: rmc00001부터 순번. 등록 시 자동 채번 또는 수동 입력 방식 확정 필요. 수정 불가.
3 카테고리명 (plain string)
한국어 단일 문자열. { ko, en } 다국어 객체 아님. 실서비스에서 다국어 구조로 전환 예정.
→ 프런트: 숙소 레이어 > 안내정보 탭 시설 그룹 헤더 / Room Detail ④ 객실시설정보 그룹 헤더
4 시설 수
해당 카테고리에 속한 시설 마스터 개수. 카테고리 삭제 시 속한 시설이 있으면 삭제 제한 필요(실서비스 정의 사항).
5 수정·삭제
수정: 카테고리 등록·수정 폼(S07-B)으로 이동. 삭제: 확인 다이얼로그 후 삭제.
시설이 존재하는 카테고리 삭제 시 해당 시설의 category_id가 무효화됨. 실서비스에서 삭제 제한 정책 필요.
