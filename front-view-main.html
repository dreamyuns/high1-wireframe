주석

1
히어로 슬라이더
메인 최상단 전체 폭. S12-B 슬라이드 설정 기반.
이미지·동영상·타이틀(KO/EN)·서브타이틀·CTA 버튼 포함.
S12-A 목록 순서대로 노출. 노출 조건(기간·force_off) 통과 슬라이드만 렌더링.
hero_pc_image / hero_mobile_image
hero_title_ko / hero_title_en
hero_subtitle_ko / hero_subtitle_en
hero_cta_use / hero_cta_label_ko / hero_cta_label_en / hero_cta_url
hero_autoplay / hero_interval_sec
hero_period_start / hero_period_end / hero_force_off
ON 슬라이드 0개 시 히어로 영역 전체 미노출.
force_off=true 시 기간 무관 즉시 미노출.
2
추천 섹션 헤더
섹션 타이틀, 서브타이틀, 전체보기 버튼. 상세는 B. 섹션·카드 상세 참조.
섹션 노출 조건: visible=true AND 기간 내 AND SHOW 객실 ≥ 1.
조건 미충족 시 섹션 전체 미노출 (빈 카드 그리드 방지).
3
2뎁스 탭 (숙소별 탭)
tab_enabled=ON + 2뎁스 2개 이상 선택 시 가로 탭 UI 표시.
 → 탭 순서: [전체] (첫 번째) + 숙소별 탭.
 → [전체] 탭: 선택된 모든 숙소의 카드를 통합 그리드로 표시.
tab_enabled=OFF 또는 선택 숙소 1개: 탭 없이 통합 그리드 (전체 탭 미노출).
section_tab_enabled / section_place_ids[]
4
객실 카드 그리드
최대 10개 카드 나열.
수동 모드: S12-C에서 관리자가 지정한 순서.
자동 모드: 정렬 기준(가격순·A-Z·인기순) 상위 순.
room.visible=SHOW인 객실만 표시. HIDE 객실 자동 제외.
section_room_ids[] (수동) / section_sort_type (자동)
SHOW 카드 0건 시 섹션 전체 미노출.

주석

5
섹션 타이틀
KO/EN 별도 입력. 언어 설정에 따라 전환. 타이틀 KO 필수.
section_title_ko / section_title_en
6
섹션 서브타이틀
선택 입력. KO/EN 별도 입력. 미입력 시 해당 라인 미노출.
section_subtitle_ko / section_subtitle_en
7
전체보기 버튼
viewall_use=ON 시 섹션 헤더 우측에 버튼 표시. KO/EN 버튼명 별도 입력.
URL 내부(/…) → 현재 탭. 외부(https://) → 새 탭(_blank).
section_viewall_use
section_viewall_label_ko / section_viewall_label_en
section_viewall_url
use=ON 시 버튼명 KO + URL 필수. 미입력 시 저장 불가.
8
2뎁스 탭
tab_enabled=ON + 2뎁스 2개 이상: [전체] 탭 + 숙소별 탭.
OFF 또는 1개 선택: 탭 없이 통합 그리드 (전체 탭 미노출).
전체 카드 상한: 10개 (탭 ON/OFF 무관).
section_tab_enabled / section_place_ids[]
9
카드 — 썸네일
S04 객실 등록 시 업로드한 대표 이미지. 미등록 시 숙소 대표 이미지 폴백.
room.thumbnail_url
10
카드 — 숙소명
언어 설정에 따라 KO/EN 전환.
place.name_ko / place.name_en
11
카드 — 객실명
언어 설정에 따라 KO/EN 전환.
room.name_ko / room.name_en
12
카드 — 인원 · 면적
형식: "기준N-최대N , Nm²" (1행 콤마 구분).
면적 미입력 시 "기준N-최대N"만 표시.
인원·면적 모두 미입력 시 해당 라인 미노출.
room.base_guests / room.max_guests / room.area_m2
⚠ S04 어드민 직접 입력. PMS 미제공 — 객실 등록 시 반드시 입력 필요.
13
카드 — 최저가
오늘부터 30일 이내 최저 판매가(마진 적용 후 고객 청구 금액). 배치 1일 2회 갱신.
값 없음(판매 가능 상품 없음·배치 실패) → 가격 영역 미노출.
room.price_min_batch (배치 계산값)
최저가는 참고용. 정확한 가격은 날짜 선택 후 브릿지 페이지에서 확인.
14
카드 — CTA 버튼
고정 텍스트 "예약하기 / Book Now". 카드 전체 클릭과 동일 동작.
클릭 시 해당 숙소 브릿지 페이지로 이동 (place·room 파라미터 포함, REF-2 참조).
