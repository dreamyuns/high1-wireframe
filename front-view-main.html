주석

1
히어로 슬라이더
메인 최상단 전체 폭. S12-B 슬라이드 설정 기반.
이미지·동영상·타이틀 EN(필수)/ZH(선택)·서브타이틀·CTA 버튼 포함.
S12-A 목록 순서대로 노출. 노출 조건(기간·force_off) 통과 슬라이드만 화면에 나타남.
※ 이미지·동영상은 파일 업로드 방식(화면기획 기준). 동영상은 프런트 미연동(이미지만 노출).
high1_main_hero_v1[] :
· pc_image / mobile_image (파일 업로드)
· title_en / title_zh · subtitle_en / subtitle_zh
· cta_use / cta_label_en / cta_label_zh / cta_url
· media_type (video는 프런트 미연동) · period_start / period_end / force_off · order
high1_main_hero_cfg_v1 : autoplay / interval_sec
ON 슬라이드 0개 시 히어로 영역 전체 미노출.
force_off=true 시 기간 무관 즉시 미노출.
※ 프런트 프로토타입은 아직 텍스트 KO/EN(title_ko/title_en 등)·이미지 URL 입력 방식 — EN/ZH·파일 업로드는 프로토타입 후속 반영 예정.
2
추천 섹션 헤더
섹션 타이틀, 서브타이틀, 전체보기 버튼. 상세는 B. 섹션·카드 상세 참조.
섹션 노출 조건: visible=true AND 기간 내 AND SHOW 객실 ≥ 1.
조건 미충족 시 섹션 전체 미노출 (빈 카드 그리드 방지).
3
2뎁스 탭
자동 모드 + 1뎁스 카테고리 2개 이상일 때 가로 탭 UI 표시.
선택 카테고리 1개 또는 수동 모드: 탭 없이 통합 그리드.
high1_main_section_v1[].room_mode (manual/auto)
· cat_1depth[] (hotel/condo) · place_ids[]
⚠ 확인 필요(대화창 1/2): 화면기획 원안은 '숙소별 탭 + [전체] 탭'이나, 프런트 프로토타입 v0.6은 '카테고리(호텔/콘도) 탭'이며 [전체] 탭이 없습니다. 어느 방식으로 확정할지 정책·화면 정합 필요.
4
객실 카드 그리드
카드 나열 (프로토타입 상한 12개).
수동 모드: S12-C에서 관리자가 지정한 순서.
자동 모드: 정렬 기준(가격순 price · A-Z az · Z-A za · 인기순 popular) 상위 순.
숙소 노출=SHOW AND 객실 노출=SHOW인 객실만 표시. HIDE는 자동 제외.
high1_main_section_v1[].room_ids[] (수동) / sort_type (자동: price/az/za/popular)
SHOW 카드 0건 시 섹션 전체 미노출.
⚠ 확인 필요: 화면기획 원안은 상한 10개이나 프런트 프로토타입 v0.6은 12개(slice 0,12). 상한 수치 확정 필요.

주석

5
섹션 타이틀
EN(필수)/ZH(선택) 별도 입력. ZH 접속 시 ZH, 없으면 EN 표시. 타이틀 EN 필수.
high1_main_section_v1[].title_en (필수) / title_zh (선택)
※ 프런트 프로토타입은 아직 KO/EN(title_ko/title_en) — EN/ZH는 후속 반영 예정.
6
섹션 서브타이틀
선택 입력. EN/ZH 별도 입력. 미입력 시 해당 라인 미노출.
high1_main_section_v1[].subtitle_en / subtitle_zh
7
전체보기 버튼
viewall_use=ON 시 섹션 헤더 우측에 버튼 표시. EN/ZH 버튼명 별도 입력.
URL 내부(/…) → 현재 탭. 외부(https://) → 새 탭(_blank).
high1_main_section_v1[].viewall_use
· viewall_label_en / viewall_label_zh
· viewall_url
use=ON 시 버튼명 EN + URL 필수. 미입력 시 저장 불가.
※ 프런트 프로토타입은 아직 KO/EN(viewall_label_ko/_en) — 후속 반영 예정.
8
2뎁스 탭
자동 모드 + 1뎁스 카테고리 2개 이상: 카테고리(호텔/콘도) 탭.
수동 모드 또는 1개 선택: 탭 없이 통합 그리드.
카드 상한: 프로토타입 12개 (CN 4 참조).
high1_main_section_v1[].room_mode / cat_1depth[] / place_ids[]
⚠ 확인 필요: 화면기획 원안(숙소별 탭 + [전체])과 프로토타입(카테고리 탭)이 다름 — CN 3 플래그 참조.
9
카드 — 썸네일
S04 객실 등록 시 업로드한 이미지 중 첫 번째. 이미지가 없으면 "No Image" 회색 박스 표시(프로토타입은 숙소 이미지 폴백 없음).
high1_rooms_v1[].image_meta[].data_url (첫 이미지)
10
카드 — 숙소명
ZH 접속 시 ZH, 없으면 EN 표시.
high1_places_v1[].place_name_en / place_name_zh
※ 프런트 프로토타입은 아직 KO/EN(place_name/place_name_en) — 후속 반영 예정.
11
카드 — 객실명
ZH 접속 시 ZH, 없으면 EN 표시.
high1_rooms_v1[].room_name_en / room_name_zh
※ 프런트 프로토타입은 아직 KO/EN(room_name/room_name_en) — 후속 반영 예정.
12
카드 — 인원 · 면적
형식: "기준N-최대N , Nm²" (1행 콤마 구분).
면적 미입력 시 "기준N-최대N"만 표시.
인원·면적 모두 미입력 시 해당 라인 미노출.
high1_rooms_v1[].standard_occupancy / max_occupancy / room_size_sqm
⚠ S04 어드민 직접 입력. PMS 미제공 — 객실 등록 시 반드시 입력 필요.
※ 프런트 프로토타입은 인원(👥 기준N / 최대N)·면적(▭ Nm²)을 두 줄로 표시. 위 1행 콤마 형식은 목표 규격.
13
카드 — 최저가
오늘부터 30일 이내 최저 판매가(마진 적용 후 고객 청구 금액). 배치 1일 2회 갱신.
값 없음(판매 가능 상품 없음·배치 실패) → 가격 영역 미노출.
room.price_min_batch (배치 계산값)
최저가는 참고용. 정확한 가격은 날짜 선택 후 브릿지 페이지에서 확인.
※ 프런트 프로토타입은 배치 필드 대신 객실·상품 재고를 실시간으로 훑어 최저가를 즉석 계산(roomStartingPrice). 배치 필드(price_min_batch)는 목표 방식.
14
카드 — CTA 버튼
고정 텍스트. 클릭 시 해당 객실 상세로 이동 (openRoomDetail — 대표 상품 id 기준).
※ 화면기획 원안 라벨은 "예약하기 / Book Now"이나 프런트 프로토타입은 "예약 확인 / Check Availability" — 최종 문구 확정 필요.
