화면 주석

1
숙소 필터 셀렉트
전체 또는 특정 숙소를 선택해 객실 목록을 필터링한다. 선택 변경 시 라우트가 #/rooms/place/:placeId 로 변경된다. 숙소 목록 화면의 '객실수' 링크를 클릭해 진입한 경우 해당 숙소가 자동으로 선택된 상태로 진입한다.
RM-LIST-01 요구사항
2
객실 목록 정렬
수정일시(updated_at) 내림차순 고정 정렬로 가장 최근에 수정된 객실이 상단에 위치한다. 사용자가 정렬 기준을 변경하는 별도 UI는 제공하지 않는다.
3
PMS 동기화 / 갱신 버튼
신규 객실은 PMS 동기화로만 생성된다(수동 신규 등록 없음). 클릭 시 PMS에서 객실(RM_TYP_CD·객실명·기준/최대 인원 등)을 불러와 목록에 주입·갱신한다. 숙소가 먼저 동기화되어 있어야 하며(미동기화 시 알럿), 소속 숙소가 없는 객실은 스킵한다.
재동기화 시 PMS 수신 필드는 갱신, 관리자 보완 필드(영문명·객실유형·침대구성·시설·크기·안내/정책·이미지)는 보존한다. 개별 객실 보완 편집은 행의 [수정] → S04 객실 등록·수정에서 수행한다.
재고·요금 동기화는 별개 — S04-INV(객실 타입 단위) 화면에서 수행. 이 버튼은 객실 정보 동기화 전용.
4
객실명 · 객실코드 병기
객실명(예: 디럭스 킹) 아래 작은 회색 글씨로 내부 객실코드(RM-####)를 함께 표시한다.
객실코드(RM-####)는 우리 시스템이 자동으로 부여하는 내부 식별자(1객실=1코드)로, 관리자가 특정 객실을 지목·검색할 때 쓴다. 목록 맨 앞의 No.(순번)은 정렬·필터에 따라 바뀌는 화면 표시용 번호일 뿐이며 식별자가 아니다.
→ 프런트: 미노출 (RM-#### · No. 모두 내부용)
RM-#### ≠ RM_TYP_CD(PMS코드). 상품연결·예약·이력 참조 키는 객실코드(RM-####). 상세: policy-decisions.html 섹션 03.
5
PMS코드 (RM_TYP_CD)
PMS 동기화로 받아오는 객실 유형 코드(RM_TYP_CD). 예: STD·JSD·DLX. 요금·재고·마진의 기준 키로, 같은 코드가 서로 다른 업장(SLST_ID)에 중복 존재할 수 있다(업장 내 고유). 객실코드(RM-####)와는 별개 개념이다.
→ 프런트: 미노출 (내부 기준 키)
원천: S04 PMS 동기화. 전 상품 PMS 연동 운영 전제. 상세: policy-decisions.html 섹션 03.
6
상품연결 수
해당 객실에 연결된 상품 수를 표시한다. 숫자를 클릭하면 상품 목록으로 이동하며 해당 객실 필터가 자동 적용된다. 0이면 프런트에서 해당 객실의 상품이 표시되지 않는다.
