화면 주석

1
숙소 필터 셀렉트
전체 또는 특정 숙소를 선택해 객실 목록을 필터링한다. 선택 변경 시 라우트가 #/rooms/place/:placeId 로 변경된다. 숙소 목록 화면의 '객실수' 링크를 클릭해 진입한 경우 해당 숙소가 자동으로 선택된 상태로 진입한다.
RM-LIST-01 요구사항
2
객실 목록 정렬
수정일시(updated_at) 내림차순 고정 정렬로 가장 최근에 수정된 객실이 상단에 위치한다. 사용자가 정렬 기준을 변경하는 별도 UI는 제공하지 않는다.
3
객실 등록 버튼
클릭 시 #/rooms/new 로 이동한다. 숙소 필터가 특정 숙소로 선택된 상태라면 #/rooms/new/place/:id 로 이동해 해당 숙소가 폼에 미리 선택된 상태로 진입한다.
4
엑스트라베드 Y/N
extra_bed_enabled 필드 값을 Y/N 배지로 표시한다. Y이면 프런트 Room Detail 모달 ② 객실정책 섹션에 '엑스트라베드' 요금 카드가 표시된다.
→ 프런트: Room Detail 모달 ② 객실정책 > 엑스트라베드 요금 카드 (활성 시만 표시)
5
추가인원비용 Y/N
occupant_extra_charge_enabled 필드 값을 Y/N 배지로 표시한다. Y이면 프런트 Room Detail 모달 ② 객실정책 섹션에 '인원추가요금' 카드가 표시된다.
→ 프런트: Room Detail 모달 ② 객실정책 > 인원추가요금 카드 (활성 시만 표시)
6
상품연결 수
해당 객실에 연결된 상품 수를 표시한다. 숫자를 클릭하면 상품 목록으로 이동하며 해당 객실 필터가 자동 적용된다. 0이면 프런트에서 해당 객실의 상품이 표시되지 않는다.
