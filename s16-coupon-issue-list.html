기준: 프로토타입 admin v0.7.31
· 조회 중심 — 쿠폰 1장 = 1행. 주문 단위는 S15. 상태변경은 하이원 POS 사용/사용취소 API 또는 주문취소(S15)로 발생하며 이 화면에서 직접 변경하지 않음.
· 쿠폰 상태 3종: 미사용(SOLD) / 사용완료(USED) / 취소(CANCELLED). (AVAILABLE·VOID 미사용)
· 발급현황에는 판매 전(AVAILABLE) 행이 없음 — 쿠폰번호는 구매 시점 생성되어 SOLD로 시작.
· 엑셀(CSV) 다운로드는 현재 필터 조건 기준 전체 행을 내려받음.

화면 주석

1
엑셀(CSV) 다운로드
현재 필터 조건 기준 전체 행을 CSV로 내려받는다. 컬럼: 쿠폰번호·주문번호·상품명·레벨·구매자·쿠폰상태·사용시작·사용종료·구매일시·사용/취소일시. 정산·리포트용.
2
통계 4카드 (전체 기준)
발급 총수 / 사용완료(USED) / 미사용(SOLD) / 취소(CANCELLED). 데이터 성격: 전체 쿠폰 집계(필터 무관). 값 형식: N 장. 총수 = USED+SOLD+CANCELLED.
3
필터 (구매일 · 쿠폰상태 · 상품 · 통합검색)
구매일 from~to · 쿠폰상태(전체/SOLD/USED/CANCELLED) · 상품(발급된 상품명 distinct) · 통합검색(쿠폰번호·주문번호·구매자명). [검색]/[초기화].
4
건수 메타
필터 적용 후 총 N장. 통계 카드(전체 기준)와 달리 필터 반영 결과 건수.
5
[표] 쿠폰번호
발급 쿠폰 12자리 바코드 값. 값 형식: 쿠폰코드3+레벨1+일련6+난수2. 데이터 성격: 구매 시 생성(읽기). 유니크(취소 번호는 재사용 가능, 사용 번호는 재사용 불가).
6
[표] 주문번호 (링크)
이 쿠폰이 속한 주문번호. 값 형식: TK-YYMMDD-NNNN. 데이터 성격: 쿠폰의 order_no(읽기). 클릭 → S15-B 주문 상세로 이동.
7
[표] 상품명 / 레벨
쿠폰의 상품명 + 레벨. 값 형식: 상품명 / LV.N 레벨명. 데이터 성격: 쿠폰 스냅샷(읽기).
8
[표] 구매자
쿠폰이 속한 주문의 구매자명. 데이터 성격: 주문 buyer.name 조인(읽기). 검색 대상.
9
[표] 쿠폰상태
쿠폰 1장 상태. 데이터 성격: 자동(POS 사용/사용취소·주문취소). 값: 미사용·SOLD / 사용완료·USED / 취소·CANCELLED. (한글 라벨 · 원시코드 병기)
10
[표] 사용기간
현장 사용 가능 기간. 값 형식: 사용시작~사용종료. 데이터 성격: 쿠폰 스냅샷(읽기).
11
[표] 구매일시
쿠폰 발급(구매) 일시. 값 형식: YYYY-MM-DD HH:MM. 데이터 성격: 쿠폰 created_at(읽기). 기본 정렬(최신순) 기준.
12
[표] 사용/취소일시
USED면 사용일시, CANCELLED면 "취소 YYYY-MM-DD", SOLD면 "—". 데이터 성격: 자동(used_at/cancelled_at, 읽기).
