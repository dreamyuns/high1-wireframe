VOID 사유

화면 주석

1
통계 카드
발급 총수 / 사용완료(USED) / 미사용(SOLD+AVAILABLE) / VOID 수를 상단에 집계. 현재 필터 조건 반영.
2
필터/검색
구매일 범위 · 쿠폰상태 · VOID여부 · 상품 + 통합검색(쿠폰번호/주문번호/구매자명).
3
쿠폰번호
고객 발급 12자리 코드(쿠폰ID 3 + 레벨 1 + 일련번호 6 + 난수 2). 예: OAT1 00014 57. High1 POS가 이 번호로 조회/사용.
4
연결 주문번호
이 쿠폰이 발급된 S15 주문. 클릭 시 해당 주문 상세로 이동. 1주문 = N장 쿠폰.
5
쿠폰 상태
AVAILABLE(미판매) → SOLD(판매, 현장 사용가능) → USED(사용완료). 구매 취소 시 CANCELED. High1 /cancel 호출 시 USED→SOLD 복원.
상태 변경은 High1 API(/use, /cancel) 또는 주문 취소(S15)로 발생. 이 화면에서 직접 상태 변경은 없음(조회 중심).
6
VOID 여부
쿠폰 무효화 처리 여부를 쿠폰상태와 별도 표시. VOID 행은 흐림 처리. (상태와 독립적인 무효화 플래그)
VOID 정의·상태와의 관계는 미결(M-05). High1 개발팀 협의 후 확정.
7
일괄 VOID
체크박스로 여러 쿠폰 다중 선택 → 상단 [일괄 VOID] 버튼 → 모달에서 일괄 처리. 선택 수 실시간 표시.
8
엑셀 다운로드
현재 필터 조건 기준 전체 쿠폰 목록 다운로드.
9
VOID 처리 모달 (개별/일괄)
개별(행 선택) 또는 일괄(체크박스 다중) VOID. 대상 쿠폰번호 목록 + VOID 사유 입력 후 처리.
★미결 M-05: VOID 처리 상세(상태 변경 여부, 회수 개념, 환불 연동 등) 정의 미확정. High1에 해당 엑셀 송부 후 재확인 예정. 현재는 기본 UI 구조만.
