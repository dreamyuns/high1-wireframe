화면 주석

0
공통정책 — 발송 유형별 이메일 템플릿
숙소·티켓의 예약/구매/취소 등 발송 유형마다 탭이 나뉩니다. 각 탭에서 고객에게 보낼 안내 문구를 관리합니다.
API(외부 서비스와 데이터를 주고받는 통로) 없이 어드민이 직접 관리하는 콘텐츠입니다.
정책 근거: 정책서 v0.11 · 12.7절. 투어 등 상품 유형 추가 시 탭 추가로 확장.
1
발송 유형별 탭 (5종)
숙소 예약확정 / 숙소 대기 알림 / 숙소 취소완료 / 티켓 구매완료 / 티켓 취소완료 5개 탭입니다.
· 숙소 대기 알림은 수기 상품 전용입니다(PMS 연동 상품은 대기 단계가 없음).
· 티켓 취소완료는 미결(신규-5) — 발송 여부가 아직 확정되지 않아 회색으로 표시됩니다.
2
발송 시점 (탭별 자동 안내)
선택한 탭의 이메일이 언제 자동 발송되는지 알려주는 읽기용 안내입니다.
숙소 예약확정 탭: PMS 연동 상품은 API 6(예약 요청) 완료 즉시, 수기 상품은 관리자가 확정했을 때 발송됩니다.
수기 상품 예약은 최초 '대기' 상태로 접수되고, 관리자가 호텔 확인 후 확정하면 이 이메일이 나갑니다.
3
안내 문구 EN (필수)
해당 발송 유형에서 고객에게 보여줄 안내 문구를 영어로 적습니다.
EN(영어)은 필수입니다. 비워두면 저장할 수 없습니다.
→ 프런트: (예약확정·구매완료 탭 한정) 예약/주문 상세 화면에도 동일 문구 표시
4
안내 문구 ZH (선택)
중국어 안내 문구입니다. 선택 입력이며, 비워두면 EN 문구로 대체되어 발송됩니다.
5
시스템 자동 삽입 항목 (편집 불가)
탭마다 시스템이 자동으로 채우는 항목이 다릅니다. 관리자가 편집할 수 없고 안내용으로만 표시됩니다.
숙소 예약확정 탭: 예약번호 · 숙소명 · 체크인/아웃 일자 · 객실명 · 결제금액이 자동 포함됩니다.
각 탭의 자동 삽입 항목은 아래 [탭별 관리 항목 요약] 표에서 한눈에 확인할 수 있습니다.
6
[저장] 버튼 — 유효성 검사
현재 선택한 탭의 문구를 저장합니다.
저장 시 안내 문구 EN이 비어 있으면 저장이 막히고 경고가 표시됩니다.
EN(영어) 필수 항목이 비어 있으면 저장 불가.
※ 티켓 구매완료 탭은 이용안내 EN · 취소·환불 EN도 함께 필수 검사됩니다(CN8 참고).
7
탭별 관리 항목 요약 표
5개 탭 각각의 발송 시점 · 자동 삽입 항목 · 관리자 편집 항목 · 프런트 연동 여부를 한 표로 정리한 개발 참고용 요약입니다(읽기용).
프런트 연동 ✅ 인 탭은 [숙소 예약확정]·[티켓 구매완료] 2개뿐입니다. 나머지는 이메일 발송 전용입니다.
8
티켓 구매완료 탭 — 카테고리별 이용안내 (특례)
티켓 구매완료 탭만 안내 문구 외에 이용안내(EN/ZH)·취소·환불 안내(EN/ZH)를 추가로 관리합니다.
전체 기본 콘텐츠 + 카테고리(1뎁스)별 오버라이드 구조입니다. 카테고리 문구를 따로 설정하지 않으면 전체 기본 문구가 대신 나갑니다(폴백).
카테고리 목록은 S17(티켓 카테고리관리)에 등록된 1뎁스 카테고리를 불러옵니다. (기존 '이용안내 콘텐츠 관리' 구조를 이 탭으로 흡수)
9
노출 채널
설정한 문구가 어디에 나가는지 안내하는 표입니다(읽기용).
이메일: 각 발송 시점에 자동 발송(티켓 취소완료는 미결이라 제외).
프런트 예약/주문 상세: 숙소 예약확정 · 티켓 구매완료 탭 문구만 프런트 상세 화면에도 표시됩니다.
→ 프런트: 예약상세(숙소) · 주문상세(티켓) 화면에 동일 안내 문구 노출
※ 미결(신규-5): 티켓 취소완료 이메일 발송 여부 및 취소 이메일 템플릿 관리 필요 여부 미확정. 확정 시 [티켓 취소완료] 탭 활성화 → 대화창 1(정책) 확인 후 반영 예정.
