화면 주석

1
기본정보 (숙소 섹션과 분리)
티켓 전용 추천 섹션의 기본 정보. 섹션 타이틀(KO 필수/EN)·서브타이틀(KO/EN)·노출 여부·순서.
S12-A [+ 티켓 섹션 추가]로 진입. 숙소 섹션(S12-C)과 저장·구조가 분리됨.
→ 프런트: 메인 티켓 추천 섹션의 제목/부제
2
노출 기간 (선택)
시작일·종료일 모두 선택 입력. 미설정 시 상시 노출. 노출 토글 OFF면 기간과 무관하게 미노출.
3
전체보기 버튼
섹션 우측 상단 '전체보기' 링크. 사용 여부 토글 + 라벨(KO/EN). 미입력 시 기본값.
→ 프런트: 섹션 헤더 우측 전체보기 링크(해당 카테고리 목록으로)
4
선택 방식 (자동 / 수동)
자동: 카테고리 필터 + 정렬 기준으로 상품이 자동 채워짐. 수동: 노출할 티켓 상품을 직접 고름.
방식 선택에 따라 아래 영역(자동=CN5 / 수동=CN6)이 전환된다.
5
자동 방식 — 카테고리 필터 + 정렬
카테고리 필터(체크박스, 미선택=전체)로 대상 범위를 좁히고, 정렬 기준(최저가 낮은순 / 이름순)으로 자동 배열.
카테고리는 S17 등록 카테고리 기준. 자동 채워지므로 상품이 늘면 자동 반영.
6
수동 방식 — 티켓 상품 직접 선택
노출할 티켓 상품을 체크로 직접 고른다(1개 이상 필수). 각 상품에 카테고리 배지 표시.
티켓 상품이 없으면 "티켓 상품 등록 후 이용" 안내. 선택 순서/구성은 저장값 기준.
7
[저장] — 유효성
필수: 섹션 타이틀(KO), 선택 방식(수동일 경우 상품 1개 이상). 저장 후 S12-A 섹션 목록에 티켓 유형으로 추가된다.
