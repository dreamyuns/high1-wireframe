S15 티켓 예약/주문 관리 — 예약관리 GNB / 티켓 예약·주문

기준: v0.8 5.3절 · 5.4절 · 8절 · 12.4절
· 주문 단위 조회. 상세·취소/환불은 S15-B 상세 페이지에서 처리([상세] 클릭 시 이동). 쿠폰 단위 현황은 S16.
· 주문상태 2종: 결제완료 / 취소완료 (티켓은 결제 즉시 쿠폰 발급이라 대기·취소요청 상태 없음, 5.3절). 사용상태(미사용/일부사용/사용완료)는 주문상태와 별개로 집계(5.4절).
· 취소/환불: 자동(S14-B 취소정책 기준 환불금액 자동 계산) / 수동(관리자 직접 입력). 취소는 전체취소만 — 부분취소·부분환불 없음.
· 주문 취소 시 연결 쿠폰 상태 SOLD → CANCELED. 수량만큼 발급된 쿠폰이 대상.
· 단품 쿠폰 취소: High1 통보 불필요(우리 DB 상태만 변경). 패키지 쿠폰 취소·변경: OTA가 High1에 API로 통보 의무 있음. 단, 통보 API는 현재 미개발(M-03) — 단품 연동 완료 후 별도 협의.
· 패키지 전용 쿠폰은 일반 쿠폰과 별도 입금가(일반보다 낮음, 하이원 별도 스펙 제공)로 운영된다.
· 고객 국적만 수집(여권번호 미수집). 쿠폰번호는 12자리(쿠폰ID 3 + 레벨 1 + 일련번호 6 + 유효번호 2).

화면 주석

1
필터 (주문일 / 사용상태)
주문 접수일은 날짜 범위로, 사용상태는 드롭다운(미사용 / 일부사용 / 사용완료)으로 거른다. 티켓은 오픈형이라 특정 이용일이 없으므로, 예전 "사용날짜" 필터 대신 연결 쿠폰의 사용 여부로 상태를 나눈다.
2
필터/검색
상태·상품 드롭다운 + 통합 검색(주문번호/고객명/연락처). 기본: 주문일 최근 30일.
3
결과 요약
현재 필터 기준 총 건수와 주문상태별(결제완료/취소완료) 집계를 상단에 표시. 티켓은 결제 즉시 쿠폰이 발급되어 '취소요청·대기' 상태가 없으므로(5.3절) 별도 대기 알림은 두지 않는다.
4
주문번호
티켓 주문 코드 ORD-YYYYMMDD-NNNNN(초안). 상세 채번 규칙은 예약관리 기획 시 확정. 1주문 = N장 쿠폰.
5
고객 정보
구매자명 + 연락처. 상세에서 이메일·국적 추가 노출(국적 = 외국인 식별, 여권번호 미수집 — v0.2).
6
수량 (레벨별)
레벨별 매수 표기(대인 N / 소인 N). 1주문에 여러 레벨 혼합 가능. 각 매수만큼 쿠폰번호 발급.
쿠폰 1개 = 1영업장 구조라서, 리프트권+장비렌탈처럼 권종을 섞어 사면 권종마다 별도 쿠폰번호가 나온다. 그래서 발급되는 바코드 개수 = 구매 수량의 합이 된다.
7
주문 상태 (2종)
결제완료 / 취소완료 2가지만 있다(5.3절). 티켓은 PG 결제 즉시 쿠폰이 발급되므로 숙소 예약과 달리 대기·취소요청 상태가 없다. 취소는 전체취소만 가능하다 — 부분취소는 없앴다.
주문을 취소하면 그 주문으로 발급된 쿠폰 전부가 SOLD→CANCELED로 바뀐다.
단품 쿠폰 취소는 우리 DB 상태만 바꾸면 되고 High1에 알릴 필요 없다. 반면 패키지(객실+티켓 묶음) 쿠폰을 취소·변경할 때는 OTA가 High1에 API로 통보해야 한다. 단, 이 통보용 API는 아직 개발되지 않았다(M-03) — 단품 연동을 먼저 끝낸 뒤 협의한다.
8
사용상태 (연결 쿠폰 집계)
티켓은 특정 이용일이 없는 오픈형이라, 날짜 대신 연결된 쿠폰이 얼마나 쓰였는지를 집계해 배지로 보여준다. 한 주문 = 여러 장(N장) 쿠폰이므로, 아래 규칙으로 한 개 상태로 묶는다.
사용상태 집계 규칙 — 유효(SOLD·USED) 쿠폰 중: 사용(USED) 0장이면 미사용, 1장~전체-1장이면 일부사용, 전부 USED면 사용완료. (예: 3장 중 1장 사용 → "일부사용 · 1/3장 사용")
주문이 취소완료면 쿠폰이 모두 CANCELED이므로 사용상태는 "—(취소됨)"으로 표시한다.
9
엑셀 다운로드
추후 논의. 현 단계 버튼 영역만 예약(비활성).
10
상세 — S15-B 이동
[상세]를 누르면 S15-B 티켓 주문 상세 페이지로 이동한다(주소: #/ticket-orders/:id). 예전에는 이 화면 안에서 모달로 처리했지만, 지금은 별도 상세 페이지에서 주문·고객·발급 쿠폰 확인과 취소/환불(전체취소만)을 처리한다.
취소/환불 처리·부분환불 제거 등 상세 정책은 S15-B 주석 참고.
11
주문일시
주문(결제 완료)이 접수된 날짜·시각. 주문상태와 사용상태 사이 컬럼으로 표시. 정산·조회 시 접수 시점 확인용. (필터의 '주문일' 범위와 동일 기준)
