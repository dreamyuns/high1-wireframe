화면 주석

1
날짜 필터 (주문일 / 사용날짜)
주문 접수일과 사용(이용)날짜를 독립 필터. 오픈형 상품은 사용날짜가 없으므로 사용날짜 필터에서 제외.
2
필터/검색
상태·상품 드롭다운 + 통합 검색(주문번호/고객명/연락처). 기본: 주문일 최근 30일.
3
취소요청 알림
처리 대기 중인 취소요청 건수를 상단 pill로 집계. 해당 행은 배경색(연주황)으로 구분.
4
주문번호
티켓 주문 코드 ORD-YYYYMMDD-NNNNN(초안). 상세 채번 규칙은 예약관리 기획 시 확정. 1주문 = N장 쿠폰.
5
고객 정보
구매자명 + 연락처. 상세에서 이메일·국적 추가 노출(국적 = 외국인 식별, 여권번호 미수집 — v0.2).
6
수량 (레벨별)
레벨별 매수 표기(대인 N / 소인 N). 1주문에 여러 레벨 혼합 가능. 각 매수만큼 쿠폰번호 발급.
7
주문 상태
결제완료 / 취소요청(처리 대기) / 취소완료(환불) / 부분취소(일부 매수만 취소·환불).
주문 취소 → 연결 쿠폰 SOLD→CANCELED. 부분취소는 취소된 매수의 쿠폰만 CANCELED.
8
사용날짜
날짜지정형 상품의 이용일. 오픈형 상품은 "오픈형"으로 표시(특정일 없음).
9
엑셀 다운로드
추후 논의. 현 단계 버튼 영역만 예약(비활성).
10
주문 상세 모달
[상세] 클릭 시 모달. 주문·고객·결제·발급 쿠폰 정보 + 취소/환불 처리 영역. 발급 쿠폰번호는 S16(쿠폰 현황)과 연결.
11
환불 계산 — 자동 (취소정책 기준)
S14-B 취소정책으로 취소 시점의 위약금율을 적용해 환불 예정액 자동 계산. 위약금 = 판매가 × 위약금율.
→ 고객 안내: 위약금·환불 예정액 표시
12
수동 입력
자동 계산을 쓰지 않고 관리자가 환불금액·위약금을 직접 입력(예외 처리·민원 대응). 숙소 예약관리와 동일 운영.
13
부분 환불
프런트는 부분 환불 불가. 어드민에서만 수동으로 일부 매수·일부 금액 환불 처리 가능(부분취소 상태).
부분취소 시 취소된 매수의 쿠폰만 CANCELED, 나머지는 SOLD 유지.
14
취소·환불 처리
확인 후 처리 → 주문 상태 변경 + 연결 쿠폰 CANCELED + 환불(결제 시스템). 처리 결과·이력 기록.
환불 실행 주체(PG 연동)는 결제 시스템 담당. 본 화면은 상태·금액 확정까지.
