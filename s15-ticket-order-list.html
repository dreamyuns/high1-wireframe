· 조회 중심 화면. 주문은 프런트 구매로 생성되고, 상태 변경은 하이원 POS 사용/사용취소 API 또는 관리자 취소(S15-B)로 발생.
· 주문상태 3종: 결제완료 / 부분취소 / 취소완료 (v0.14 부분취소 신설).
· 사용상태 3종(+—): 취소 제외 활성 쿠폰 기준 미사용 / 일부사용 / 사용완료. 주문상태와 별개 개념.
· 관리자 부분취소는 S15-B 상세에서 상품·수량 단위(미사용 SOLD & 사용종료일 이전만). 취소는 프런트 마이페이지에 재진입 시 반영.
· 입금가(원가)는 목록에 없음(상세 어드민 전용). 결제금액=판매가 합.

화면 주석

1
필터 (주문일 · 주문상태 · 사용상태 · 통합검색)
주문일 from~to 범위 · 주문상태(전체/결제완료/부분취소/취소완료) · 사용상태(전체/미사용/일부사용/사용완료) · 통합검색(주문번호·구매자명·연락처). [검색]/[초기화].
취소일 기준 조회·환불금액 표시는 별도 "티켓 취소 목록" 뷰(#/ticket-orders-cancelled)에서 제공(주문일→취소일, 환불금액 컬럼 추가).
2
건수 메타 + 부분취소 pill
필터 적용 후 총 N건 표시. 부분취소 주문이 있으면 부분취소 N건 pill을 함께 노출(운영자 주의 환기).
3
[표] 주문번호
주문 고유번호. 값 형식: TK-YYMMDD-NNNN. 데이터 성격: 프런트 구매 시 생성(읽기). 데모 데이터는 옆에 데모 배지.
클릭/[상세] → S15-B 주문 상세로 이동.
4
[표] 구매자
구매자명 + 하단 국가(국적) 서브텍스트. 값 형식: 성명 / 국가명. 데이터 성격: 프런트 주문의 buyer 정보(읽기). 외국인 대상이라 국가 표시.
5
[표] 연락처
구매자 휴대폰. 값 형식: 국가번호 포함(예 +82/+1/+86). 데이터 성격: 프런트 주문 buyer.phone(읽기). 국적으로 국가번호 유추 표시.
6
[표] 대표상품
주문의 첫 상품명 + 외 N종(상품 2개 이상 시). 값 형식: 상품명 외 N종. 데이터 성격: 주문 items 집계(읽기). 상세는 S15-B에서 전체 확인.
7
[표] 발급매수
이 주문으로 발급된 쿠폰 총 매수. 값 형식: N매. 데이터 성격: 연결 쿠폰(취소 포함) 개수 집계(읽기).
8
[표] 주문상태 (3종)
주문 단위 상태. 데이터 성격: 자동(결제·취소로 변동). 값 3종:
배지의미
결제완료PG 결제 완료·쿠폰 발급(대기 없음)
부분취소일부 쿠폰 취소·부분 환불(v0.14 신설)
취소완료전체 취소·환불 완료
9
[표] 사용상태 (3종 + —)
현장 사용 진행 상태. 데이터 성격: 취소 제외 활성 쿠폰 기준 집계(읽기). 주문상태와 별개. 값:
배지조건
미사용활성 쿠폰 전부 SOLD
일부사용일부만 USED
사용완료활성 쿠폰 전부 USED
—활성 쿠폰 없음(전체취소 등)
10
[표] 주문일시
주문 접수 일시. 값 형식: YYYY-MM-DD HH:MM. 데이터 성격: 주문 created_at(읽기). 목록 기본 정렬은 주문일시 최신순.
11
[표] 결제금액
고객 결제 총액(판매가 합). 값 형식: NN,NNN원. 데이터 성격: 주문 total(읽기). 입금가(원가)는 목록 미표시 — 상세(S15-B)에서 어드민 전용으로 확인.
12
[표] 상세
[상세] 버튼 → S15-B 주문 상세(구매자·발급 쿠폰·결제/환불·처리 이력·관리자 부분취소). 행 클릭으로도 이동.
