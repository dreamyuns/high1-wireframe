화면 주석

1
대표 이미지 (필수)
숙소당 대표 이미지 1장은 필수이다. 저장 시 image_meta.length >= 1 조건을 검증하며, 미등록 상태에서 저장 시도 시 저장을 차단하고 오류 메시지를 표시한다. 등록된 이미지 중 첫 번째가 대표 이미지로 사용되며, 대표 이미지 삭제 시 다음 순서의 이미지가 자동으로 대표로 승격된다.
→ 프런트: 브릿지 페이지 풀와이드 히어로 이미지. 2장 이상 시 캐러셀(← →) 자동 활성.
2
추가 이미지 (최대 9장)
대표 이미지 외 추가 이미지를 최대 9장까지 등록할 수 있다. 각 이미지는 개별 삭제가 가능하며, 등록 순서대로 프런트에서 표시된다. 순서 변경 기능은 현재 미지원이며, 실서비스 시 드래그앤드롭 정렬 기능 추가를 고려한다.
→ 프런트: 히어로 캐러셀 추가 슬라이드 / Room Detail 갤러리 그리드(최대 5장)
3
파일 크기 제한
파일당 최대 2MB(PLACE_IMAGE_MAX_MB 상수)로 제한된다. 제한을 초과하는 파일은 해당 파일만 거부하고, 파일명을 포함한 오류 메시지를 표시한다. 나머지 파일은 정상적으로 처리되므로 일부 파일만 초과하더라도 나머지는 업로드된다.
localStorage 저장이므로 이미지 수 × 평균 크기가 총 용량에 영향. 용량 부족 시 Quota 초과 오류 발생.
4
Quota 초과 경고
localStorage 저장 용량(보통 5~10MB)을 초과하면 경고 블록을 표시하고, 전역 에러 요약(#wiz_err)에도 반영하며, 3단계(이미지 단계)로 자동 이동한다. 이미지를 삭제하거나 크기를 줄인 후 다시 저장을 시도해야 한다.
Quota 초과는 이미지 외 HTML 필드에 붙여넣기 이미지가 쌓였을 때도 발생 가능.
