브릿지 페이지 주석 (callout ①~⑭)

1
숙소 선택 탭
GNB 탭에서 선택한 type(HOTEL/CONDO)에 해당하는 숙소 목록을 탭으로 나열. 탭 클릭 시 해당 숙소 데이터로 전환.
어드민 S02-1 Step1 · 숙소명 / 1차 분류
h1_places[].place_name · h1_places[].category
탭 텍스트 = place_name, HOTEL/CONDO 기준 필터
2
Hero 이미지 슬라이더
숙소 이미지 배열을 슬라이더로 표시. ← → 버튼으로 순환. 이미지가 없으면 placeholder 표시.
어드민 S02-3 Step3 · 이미지 등록 (images 배열)
h1_places[].images[].data_url
Hero 배경 이미지 슬라이더
3
Hero Overlay — 숙소명 · 2차 분류명
Hero 이미지 위 어두운 overlay에 숙소명(상단)과 2차 분류명(하단)을 표시. "숙소 안내 보기" 버튼 클릭 시 장소 레이어 오픈.
어드민 S02-1 Step1 · 숙소명 / 2차(건물·단지)
h1_places[].place_name · h1_places[].sub_place
Hero overlay 1행(숙소명) / 2행(2차 분류명 — subLabel 함수로 가공)
4
Sticky Nav 탭 동작
탭별 동작이 다르게 작동합니다.
Overview / Rooms → 해당 섹션으로 페이지 내 스크롤
안내(detail) / 정책(policies) / 위치(location) → 우측에서 장소 레이어 슬라이드인 팝업 (REF-3 참조)
레이어 탭 데이터 출처: 안내→guide_html, 정책→policy_html, 위치→location_detail
5
Overview — 체크인 · 체크아웃 시각
Overview 섹션 좌측에 기본 체크인/아웃 시각 표시. HH:MM 형식.
어드민 S02-1 Step1 · 체크인(기본) / 체크아웃(기본)
h1_places[].check_in · h1_places[].check_out
Overview 섹션 좌측 정보 패널
6
Overview — 대표 시설 칩 (PLACE)
Overview 섹션 우측에 대표 시설을 칩(chip) 형태로 나열. ★ 대표로 설정된 시설만 표시. 최대 10개.
어드민 S02-5 Step5 · ★ 대표 시설 선택 (PLACE 도메인)
h1_places[].featured_facility_ids → h1_facilities[].name
Overview 대표시설 칩 나열 (최대 10개)
facility_ids의 부분집합. 최대 10개 초과 시 어드민 저장 차단.
7
날짜 피커 — CHECK-IN / CHECK-OUT
체크인·아웃 날짜 입력 후 Search 클릭 시 evaluateProductForStay()가 각 상품의 재고·요금 상태를 계산하여 카드에 반영.
어드민 S05-A/B · 재고·요금 등록 (날짜별 inventory)
h1_products[].inventory[YYYY-MM-DD].{price, stock, sale_closed}
날짜 미선택 → "날짜를 선택하세요" / 선택 후 → 요금 or 상태 메시지
evaluateProductForStay 판단 순서: need_dates → sale_out → no_inv → closed → cutoff → soldout → ok
8
2차 분류 뱃지 (건물·단지명)
상품 카드 최상단에 소속 건물·단지명을 작은 뱃지로 표시. subLabel() 함수를 통해 category + sub_place 조합으로 가공.
어드민 S02-1 Step1 · 2차(건물·단지) 드롭다운
h1_places[].sub_place (예: "Grand Convention")
카드 최상단 뱃지 텍스트 (예: 하이원컨벤션타워)
9
객실명 + 상품명
객실명(작게)과 상품명(크고 굵게) 2줄로 표시. 같은 객실에 여러 상품이 있으면 상품마다 별도 카드로 출력.
어드민 S03 객실 등록 · 객실명 / S04 상품 등록 · 상품명
h1_rooms[].room_name · h1_products[].name
카드 1행(객실명 — 연한 색) / 2행(상품명 — 굵게)
10
침대 정보 + 인원
침대는 "{침대유형} {개수}개" 형식으로 복수 나열. 인원은 기준/최대로 표시.
어드민 S03 객실 등록 · 침대유형 / 기준인원 / 최대인원
h1_rooms[].bed_types[]{type,count} · h1_rooms[].standard_occupancy · h1_rooms[].max_occupancy
카드 침대 행: "침대: {유형} {N}개, … · 기준 N명 / 최대 N명"
11
객실 대표 시설 칩 (ROOM)
객실에 설정된 대표 시설을 칩으로 나열. PLACE 도메인 시설(숙소 전체 시설)과 별개로, ROOM 도메인 시설(객실별 시설)에서 대표로 선택된 항목.
어드민 S03 객실 등록 · 시설 선택 (ROOM 도메인, 대표 설정)
h1_rooms[].featured_facility_ids → h1_facilities[].name (ROOM 도메인)
카드 시설 칩 행
12
취소정책 표시 (날짜 계산)
상품의 취소 정책에서 무료 취소 가능 일수를 읽어 아래 로직으로 표시합니다.
어드민 S06-A 취소정책 → cancel_policy_type / cancel_free_days_before
h1_products_v1[].cancel_policy_type · h1_products_v1[].cancel_free_days_before
blockDate = check_in_date − N일  (이 날부터 취소 차단)
lastFreeDate = check_in_date − N − 1일  (무료취소 마지막 날)
today < blockDate → "{lastFreeDate} 23:59까지 무료취소 가능" (파란 텍스트)
today ≥ blockDate → "취소 및 환불불가" (빨간 텍스트)
cancelSummaryLine() 함수가 판단. 날짜 미선택 시 미표시.
15
Overview — 숙소 소개 (description)
Overview 섹션 하단에 숙소 소개 문구를 표시. 비어있으면 해당 영역 미노출.
어드민 S02-1 Step1 · 숙소 소개 textarea
h1_places[].description (plain text)
Overview 섹션 하단 — 체크인/시설 아래 구분선 이후 소개 문구 1단락
13
판매가 (evaluateProductForStay)
체크인·아웃 날짜 기준 전체 박 합산 요금. 상태에 따라 요금 또는 메시지 표시.
어드민 S05-A/B · 날짜별 판매가(price) 등록
h1_products[].inventory[날짜].price (1박 단가 합산)
ok → "MEMBER RATE + KRW 금액" / 그 외 → 상태 메시지 (매진/운영중단 등)
14
상품 설명 (description)
상품 카드 하단 회색 박스에 상품 설명 텍스트 표시. 비어있으면 박스 미출력.
어드민 S04 상품 등록 · 상품 설명 textarea
h1_products[].description (plain text)
카드 하단 회색 박스 (설명이 없으면 미표시)
